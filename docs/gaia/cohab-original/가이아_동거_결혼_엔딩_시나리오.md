# 6. 엔딩 후 생활 (반복)

## 안내 · 남편 (남자별 이름으로 치환)
남편: 스탯표 봐라. 평균이 75 밑으로 떨어지면 집 못 들어온다. 센터 가서 올려 와.
주인공: 네!! 다녀오겠습니다!! 올라오면 바로 안겨 있겠습니다!!
(이후 기존 G 재교육 블록: 「집 입구 잠김」 → 센터 → 「복귀」가 그대로 반복)

## 반복 풀 (모두 기존 블록)
- 아침·저녁·야간 데이트: 4권 F 「남편이 있는 경우」
- 남편 이벤트: 5권 D-남편1~3 (D-남편2는 지안 생일 기념일에만)
- 동거 일상: 5권 D-표, D-식탁, D-방문
- 주간 반복: Q30 일요일 오후(오 부장), Q28·Q29·Q40(1회)
- 센터 복귀: D4, E12
- 여기에 복도 돌발 대사(`가이아_복도_돌발대사`)가 걷는 동안 섞인다.

## 구현 메모 [임시]
- 선택된 남편은 한 번 확정되면 바꾸지 않는다. 대사 치환은 이름과 말투만이고, 다른 장면은 모두 같다.
- 엔딩은 한 번만 재생하고, 이후에는 같은 세이브에서 계속 플레이한다.
- 코드에 넣기 전에 텍스트로 케인 확인.
