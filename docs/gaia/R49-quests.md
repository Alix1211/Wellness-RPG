# R49 퀘스트 Q01~Q40 연결 (2026-10-21)

대사는 `ROOM_DIALOGUE_v3.md`(Q1~Q15)와 `QUESTS_DRAFT_1.md`(Q16~Q40) 본문을 그대로 사용한다(`tools/gaia/quest_parse.py`가 읽어 들임).
조건·보상 수치는 문서의 **제안값 그대로**이며 미확정이다. 조정은 `tools/gaia/r49-patch.py`의 표 `S` 한 곳에서 한다.

## 진행 방식
- 방 안에서 `! 부탁`(또는 퀘스트 메뉴)에서 수락 → 의뢰 대사 → 심부름/게임/도착/대화 → 완료 대사 → 보상(골드·스탯·HP).
- 종류: 심부름(받아서 의뢰한 방으로 돌아가기), 도착(목적지에 가면 완료, 진행 대사 있음), 대화(수락 즉시 완료), 게임(기존 미니게임 1회).
- 한 번만 가능. 선행 퀘스트·스탯·평균·입사·결혼·야간·일수 조건은 `qGate()`에서 판정.
