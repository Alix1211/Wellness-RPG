# R5 — 공통 선택 메뉴와 대화 흐름

## 규칙 (케인 지시)
- 사람(미션방 포함): 처음 선택지는 `대화 · 취소`. 퀘스트가 있으면 `퀘스트` 한 칸 추가.
- 대화가 끝나면 다음 행동이 한 번만 열림: `게임 시작`(물병은 1/2단계), 접수·근무 같은 서비스, `퀘스트`, `나가기`.
- 가게(shop/store/market/cafe): `구매 · 취소`. 구매를 누르면 점원 인사 대사 후 상품 창.
- 집·휴게 같은 장소(villa/homeBedroom/recovery/lounge/pantry/bus): 대화(있으면) + 해당 행동 + 퀘스트 + 취소를 한 목록으로.
- 조작: 터치, 방향키/WASD, 패드 십자키·왼쪽 스틱으로 이동, Enter/Space/Z/패드 A 확정, Esc/Backspace/X/패드 B 취소(대화 중에는 메뉴로 복귀).
- 기존 서비스 버튼(`serviceButtons`)은 그대로 두고 `cmRoomButtons`가 읽어서 메뉴 항목으로 변환 — 기능이 버튼을 직접 만들지 않아도 됨. 새 기능은 `serviceButtons`의 `add()`에 등록하면 자동으로 메뉴에 들어감.

## 같이 고친 것
- 이름표를 말풍선 위 칩으로 분리, 말풍선 글자 크기와 세로 가운데 정렬.
- 알림창과 목표 말풍선이 대화 화면에서 겹치던 문제 제거(대화 중 목표 칩 숨김), 알림창 위치 이동.
- 도로 상단: 목표 말풍선을 왼쪽으로 옮겨 오전/돌아가기와 겹치지 않게 함.
- 기존 대사는 한 줄도 바꾸지 않음. 남자 NPC 실루엣은 임시 에셋 그대로(초상화 에셋 필요).

## 아직 안 한 것
- 게임 중·직후 결과별 반응 대사(대사 자체가 없음), 초상화 표정 자동 전환, 오프닝 방 배경.
- 패드: 이 메뉴만 지원. 필드 이동/액션 패드 지원은 없음.
