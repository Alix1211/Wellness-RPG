## 변경
- 센터·회사 전 층: 작은 방 그림 + 코드로 그린 좁은 복도/벽. 같은 종류·같은 게임인 중복 방을 묶음.
- 엘리베이터는 벽면의 방 그림과 같은 높이에 부착. 기존 엘리베이터 그림과 문 열림/층 이동 기능 유지.
- 위/아래 입력으로 이동하거나 방향을 바꾸지 않음. 좌우 이동만 가능.
- 원하는 방 앞에서 확인 버튼으로 진입. 엘리베이터 앞에서 확인하면 층 선택.
- 조작 설명문 추가 없음. 기존 인물 크기 수정값 유지.
- 기존 집 배경/계단은 유지하되, 집 단면에서도 위/아래 이동·앞뒤 보기를 없애고 계단/출구는 확인으로 실행.
- 게임이 다른 방은 유지: 줄/배팅, 균형/스쿼트, 백만대/뒤를 조심, 회사 개인 사무실 A/B.
- 합쳐진 원래 방 ID는 prototypeAliases로 보존. R61_HOME/OWNER의 미정 인물 담당을 새로 정하지 않음.
- 시나리오·대사·퀘스트 데이터 및 성장 수치 변경 없음. script16만 수정.
