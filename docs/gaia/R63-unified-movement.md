# R63 — 벨트스크롤·버튼 출입 통일

R62 기반. 집 1층·2층·지하·단칸 빌라의 수직 이동 잠금을 해제했다.
집의 기존 단면 배경과 연속 방 구역, 센터·회사의 복도와 개별 방 구조는 유지한다.

- 실내와 거리 지도에서 방향 입력은 이동만 수행한다. 자동 계단·문·가장자리 전환을 제거했다.
- 복도/집에서는 기존 행동 버튼으로 가까운 문·계단·엘리베이터를 사용한다.
- 개별 방에서는 하단 출구 부근(y >= 635)에서 행동 버튼으로 복도로 나온다.
- 문 그림 터치가 조이스틱이나 별도 즉시 이동 경로가 되지 않도록 입력 경로를 단일화했다.
- 계단 도착 y=575. R62의 입력 해제·쿨다운·반대 계단 밖 도착 처리는 유지한다.
- 센터·회사 현관(x=95)과 엘리베이터(x=180)의 행동 판정이 겹쳐도 현관이 엘리베이터를 가로채지 않게 범위를 줄였다.
- 스티커 이미지·종류·이벤트는 유지하고, 필드에서는 캐릭터 반대쪽 화면 상단에 표시한다.

`portal-controls-fix.mjs`가 R62 이후 R63 변환을 적용한다. 오프라인 복원은 같은 JSON 패치 테이블을 읽는다.
기존 manifest transform 식별자는 유지하며 build/output 해시로 R63을 검증한다.
대사·퀘스트·성장·미니게임 스크립트는 R62와 바이트 동일. 배경 이미지 제작·교체, NPC 크기 조정은 포함하지 않는다.

검증:
- `node tests/gaia/verify-unified-movement.cjs /tmp/gaia-r62 /tmp/gaia-r63`
- 23개 script 문법, 변경 대상 외 20개 script 바이트 동일.
- 모든 사용 층의 상하 이동, 집 계단 전 경로·현관 행동, 센터·회사 현관/엘리베이터 구분.
- 실제 update 함수로 각 집 층에서 상하좌우 180프레임 입력 유지 시 장면 변경 없음.
- 웹 변환·오프라인 복원·다운로드용 HTML 일치 및 출력 SHA-256 확인.

검증 한계: 로컬 Playwright 브라우저 실행 파일이 없어 화면·실기기 확인은 수행하지 못했다.
그림에 맞춘 바닥의 세부 조정과 NPC 외형 정합성은 추가 시각 확인이 필요하다.
