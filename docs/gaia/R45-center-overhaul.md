# R45 센터 전면 개편 (2D 단면 · 횡스크롤)

- 센터 1~5층을 가져오신 그림 10장으로 교체. 층↔그림: 1F=2·3 / 2F=4·1 / 3F=9·7 / 4F=8·10 / 5F=6·5 (각 그림 가운데에서 둘로 나눠 한 층 4구역).
- 구역: 1F 현관·로비·매점·휴게실 / 2F 기초반A·B·화장실·휴게실 / 3F 기구방A·B·C·휴게실 / 4F 단체방A·B·요가방A·B / 5F 통창방A·B·화장실·휴게실.
- 방 입장 없음. NPC에게 말을 걸면 그 뒤 화면을 흐리게 한 대화창 → 메뉴(게임·퀘스트) → 청원 장면 → 게임.
- 퀘스트 표시는 구역 담당자 머리 위 분홍 '!'.
- 유리·지안은 같은 시간대에 한 곳에만 등장(시간대=날짜+슬롯). 조교는 한 층 안에서 구역마다 다른 사람.
- 대화 초상: 가로·세로 모두 높이 기준으로 통일(세로에서 폭 기준 150%이던 것 제거). 오 부장 합장 SD 포즈 제거.
- 옛 6층(집중 훈련층)은 숨김(미사용), 옛 저장의 방 장면은 복도로 보정.
- 복도 사진 꾸미기(벽 사진 칸)는 센터에서 표시하지 않음(회사·거리는 그대로).
- 회사·거리는 이번 범위가 아님(기존 구조 유지).
- 패치: tools/gaia/r45-patch.py
