## 검증 사실
`tests/gaia/repair-verification.json`에 8개 항목 통과와 브라우저 pageerror 없음 기록. 800×1280 터치 환경 사용.
- 실제 터치: 도로 점프, 가속 버튼 전달, 일반 필드 점프, 거리 이벤트 종료 뒤 점프.
- 정상 이동 도착 훅을 통해 +10G 지급 및 자동 접수 연결 확인.
- 각 방 게임 시작은 실제 실행. 완료 결과 메시지는 테스트가 주입하여 호스트 진행 전환을 검사. 미니게임을 모두 손으로 이긴 검증이 아님.
- 거리 이벤트 WebAudio running/배경 루프/타격음 노드 시작 확인. 스피커 청취 아님.
- 23개 최상위 script 문법 검사 통과. Android Chrome 실기기 및 APK 테스트 미실시.
- 예전 `runtime-verification.json`/`verify-life.cjs`는 이전 수동 심야 버튼을 전제로 한 기록이다. 최신 검증으로 사용하지 말 것.

## 내일 수동 점검 순서
1. 기존 저장을 JSON으로 내보내고 별도 브라우저 프로필에서 새 게임 실행. 기존 저장/IndexedDB 그림을 지우지 말 것.
2. 첫 화면부터 마우스 API 호출 없이 터치/클릭으로 저녁거리 수락·수령·전달·혼잣말·센터 목표를 확인. 의뢰가 숨겨지거나 진행이 끊기면 기록.
3. 센터까지 실제 도로 이동. 달리기·점프·거리 이벤트·이벤트 종료 후 재입력을 반복.
4. 도착 +10G가 한 번만 들어오는지, 접수 전/후 잔액이 정확한지 확인. 새 저장 기본값 기준 −120→−110→−350G. 저녁거리 보상20G를 먼저 받았다면 금액이20G 높음.
5. 접수 대사를 끝까지 진행하고 방 5곳을 직접 플레이. 목표·지도·층·방 강조가 바뀌는지, 게임 프레임이 남지 않는지 확인.
6. 낮/심야, 성공/실패/포기, HP0, 음소거/음향 켜기, 다른 앱 다녀오기, 저장 후 재실행 확인.
7. 기존 세이브로 되돌려 그림 편집·복도 장식·직업·관계·돈이 유지되는지 확인.
8. 첫날 이후 최소2~3일 실제 플레이로 수치 하락/성장/회복/돈/직장 잠금이 반복 가능한지 평가. 밸런스 모델 검사는 실제 재미 검증을 대신하지 못함.

## 실행과 수정
복원한 GAIA-LIFE-20261020.html은 외부 자산 없이 Chrome에서 열 수 있다. index.html 로더는 HTTP 서버가 필요하다. 서버 사용 시 저장 원점이 달라지므로 기존 file/content:// 세이브와 별개임에 주의.
```
python3 tools/gaia/restore.py
python3 -m http.server 8000
# http://localhost:8000/GAIA-LIFE-20261020.html
python3 tools/gaia/edit-html.py extract --html GAIA-LIFE-20261020.html
# .gaia-edit/script-XX.js에서 필요한 코드만 수정
python3 tools/gaia/edit-html.py pack --output gaia-edited.html
```
추출/재조립은 원본 스크립트와 HTML 틀을 그대로 보존한다. 수정 없이 pack하면 SHA256이 위 값과 같아야 함. 추출 파일에는 거대한 임베디드 이미지/음향이 있으므로 전체를 콘솔에 출력하지 말 것. JSON 문자열 속 HTML에 raw </script>를 넣으면 부모 HTML이 깨진다. `<`를 `\u003c`로 이스케이프해야 한다.

`src/gaia-life/`의 JS/CSS는 이번 추가 로직의 읽기용 원본이다. 이 파일만 바꿔서는 복원한 실행 HTML이 갱신되지 않는다. 최상위 script를 추출해 실제 host/addon 코드와 대조·반영해야 한다. `build-life.py`/`repair-build.py`는 최초 작업 환경의 원본경로와 자산에 의존하는 참고 빌더로 보관했으며 이 저장소에서 그대로 실행하는 최신 빌드 명령이 아니다.

저장 키: gaia-rpg-road-v1 / gaia-rpg-road-world-v1. 자동 이전진행 백업은 gaia-rpg-road-v1-previous. JSON 내보내기/가져오기와 IndexedDB 미디어 편집은 별개다.
