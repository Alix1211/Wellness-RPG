복원 HTML은 file://로도 자산 없이 실행 가능. HTTP/file/content 원점이 바뀌면 기존 세이브도 달라 보일 수 있음.
Playwright 설치 환경: `npm install --no-save playwright`, `npx playwright install chromium`. `SKIP_SHOTS=1 node tests/gaia/verify-final.cjs`. 시스템 Chromium이면 CHROMIUM_PATH 지정. 자동 테스트 결과는 실제 폰 스피커 청취를 대신하지 못함.

src/gaia-life 모듈은 추가 구현/패치의 원본. 이 파일만 수정해도 실행 HTML은 자동 갱신되지 않는다. build-life.py → repair-build.py → final-fixes.py 순으로 원래 환경에서 패치했음. 빌더는 원본/자산의 작업환경 경로에 의존하므로 다른 기계에서는 복원 HTML의 추출·재조립이 이식 가능한 수정 경로다. final-child.js는 injectGame()이 기존 bridge 뒤에 삽입한다.
