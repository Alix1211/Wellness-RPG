# R62 — 출입 반복·조이스틱 충돌·거리 달리기 수정

## 원인

- `centerTap`이 조이스틱 영역 여부를 확인하기 전에 계단·출구를 클릭 처리했다.
- 벨트스크롤 복도에서도 방 클릭 범위와 왼쪽 조이스틱 시작 영역이 겹쳤다.
- 집 계단의 도착 x가 반대편 계단 판정 안에 놓여 있었다.
- 쿨다운만 있고 실제 입력 해제 조건이 없어서, 입력 유지·재입력 시 전환을 다시 일으킬 수 있었다.
- R30에서 넣은 `cityTestEnc`가 고정된 왼쪽 하단에 남아 거리의 실제 달리기 조작을 가렸다.

## 변경

- 조이스틱 영역 터치는 문·계단·사진 클릭보다 먼저 이동 입력으로 분리.
- 계단 클릭 범위를 화면 전체 세로 영역에서 실제 표시 위치(표지판 부근)로 축소.
- 계단 도착은 반대 계단·현관 판정 범위 밖의 가까운 안전 위치를 선택.
- 키/터치의 물리적 누름 상태를 `resetInput`의 논리적 초기화와 따로 추적.
- 장면 전환 후 쿨다운과 실제 입력 해제를 모두 만족해야 문·계단·엘리베이터·출구 재진입 가능.
- 거리의 강제 실린더 테스트 버튼·주기 타이머 제거. 기존 달리기/누르고 가속/점프/랜덤 만남은 보존.

대사·캐릭터·이미지·음원·퀘스트·미니게임 규칙은 변경하지 않음.
R61 대비 script-13(거리 UI), script-16(입력·출입)만 변경. 나머지 21개 스크립트 바이트 동일.

## 검증

```
node tests/gaia/verify-portal-controls.cjs R61_EXTRACTED R62_EXTRACTED
node tests/gaia/verify-belt-restoration.cjs R60_EXTRACTED R62_EXTRACTED
```

- 지하↔1층·1층↔2층 모든 계단 왕복 경로.
- 도착점이 반대 계단·현관 판정 밖인지 확인.
- 입력을 누른 상태로 180프레임 반복해도 재이동 없음.
- 키 놓기·터치 떼기·pointercancel 뒤 재사용 가능.
- 실제 canvas pointerdown 처리에서 문과 겹친 조이스틱 터치가 방 입장 대신 조이스틱을 시작함.
- 낮은 위치의 계단 오클릭 방지, 표시된 계단 클릭은 정상.
- 테스트 버튼 제거, 그 뒤 실제 거리 달리기 처리 코드는 R61과 동일.
- 벨트 이동·방 입퇴장·엘리베이터 분기·기존 저장 이관 회귀 검사.
- 웹 변환과 오프라인 복원의 출력이 테스트한 R62 HTML과 바이트 동일.

브라우저 화면·실기기 터치 테스트는 별도 확인 필요. 이번 검사는 실제 함수를 추출해 실행한 코드 검사이며 실기기 플레이 완료를 뜻하지 않는다.
