- 남성: 누구에게나 반말·하대, 거칠고 과장됨. 이년·저년·암캐·시팔년·늙은 보지 등. 금전·노동을 강요하지 않는다. 여성이 알아서 바친다.

# 확인 요청
1. 거칠고 음탕한 정도가 맞는지, 더 올릴지 낮출지.
2. 여성의 앙앙·헥헥과 스위치 대사("수고하셨습니다!! 감사합니다!!!") 비중.
3. 고칠 대사는 번호(D1, A2, Ob3 등)로 알려주시면 됩니다.
4. 남성 신입 이름은 임시 표기입니다. 이름은 케인님이 정하시면 반영합니다.
5. 집·거리·공원 쪽 인물 대사는 이번 초안에 포함하지 않았습니다.
