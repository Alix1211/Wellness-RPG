# GAIA 핑퐁 챔피언 — 프로젝트 기준 및 작업 상태

최종 수정일: 2026-10-23 (KST)
담당: 이관우(케인) / AI 협업
GitHub 기준: `Alix1211/Wellness-RPG`, 작업 브랜치 `codex/gaia-pingpong-v5`
이 문서는 **탁구 게임 전용**입니다. 웰니스 센터 시뮬레이션이나 Wellness RPG와 진행·보상을 섞지 않습니다.

## 1. 반드시 지킬 작업 원칙

1. 사용자는 디자이너입니다. 화면을 게임답게 만들고, 설명문·웹페이지 같은 상시 패널을 늘리지 않습니다.
2. **사용자의 명시적 작업 지시 없이 코드를 수정하거나 배포하지 않습니다.** 논의·검토와 실행을 구분합니다.
3. v2/v3/v4를 보존하고 이후 수정본은 버전을 올립니다. 수정 직후 `WORKLOG.md`의 완료·미검증 사항을 갱신합니다.
4. 실제 원본 에셋과 three.js 탁구 경기 물리/회전/카메라/줌을 유지합니다. 미니게임도 GAIA CASUAL 원본을 사용합니다.
5. 세이브를 보존하고, 모델 자동 테스트와 실제 브라우저/Android 실기기 검증을 구분해서 기록합니다.
6. 파일이 없거나 검증하지 못했으면 완성·확인했다고 말하지 않습니다. 링크는 실제 확인한 파일만 안내합니다.

## 2. 최신 확정 구조

- 타이틀: **아케이드 / 월드투어 / 설정**. 각 모드 별도 화면.
- 아케이드: 동네 8명 / 국내 8명 / 세계 10명. **월드투어에서 실제 승리한 선수만 해금**; 아케이드 재대결은 스토리 성장 없음.
- 월드투어: 지역별 체육관 이미지 **고정 배경**, 연결 노드와 현재 위치만 스크롤. 상단 HP·진행, 하단 이동 카드. 이동 카드 1~4칸, 이동 티켓 최대 2장.
- 경기: 기존 three.js 3D 공/라켓 물리, 탑스핀 기본·누를 때 백스핀, 5점 선취·2점 차.
- 성장: `charm` 색기 / `power` 음란도 / `defense` 복종도 / `spin` 개방성. 시작 성장 0에 실제 경기 능력 60. 누적 성장형으로 시간이 지났다고 감소하지 않음.

## 3. 미니게임 노드 — 2026-10-23 사용자 수정 지시

**지역이 넓어질수록 훈련 노드도 늘어야 합니다.** 8종의 게임 수를 노드 수로 오해하지 않습니다.

| 지역 | 총 노드 구간 | 훈련 노드 확정 목표 | 자동 배정 스테이지 | 각 주 스탯의 노드 수 |
|---|---:|---:|---|---:|
| 동네 | 0~36 (36칸 이동) | 12개 | 1~3 | 3개 |
| 국내 | 0~48 (48칸 이동) | **16개** | 4~6 | 4개 |
| 세계 | 0~60 (60칸 이동) | **20개** | 7~10 | 5개 |
| **전체** | | **48개** | | 각 스탯 12개 |

- 훈련 노드마다 미니게임이 **미리 고정 배치**됩니다. 플레이어가 미니게임·단계를 고르는 선택 메뉴는 없습니다.
- 노드에 도달하면 그 노드의 게임과 단계가 바로 실행됩니다. 게임 아이콘이 제작되기 전에는 노드 중앙에 **게임명**을 표시하고, 주 성장 스탯을 작은 표식으로 표시합니다.
- 8종이 각 지역에 모두 등장하되, 16/20개인 지역에서는 적절히 반복합니다. 주 성장 스탯 4종의 빈도를 균등하게 합니다.
- 기존 v4 훈련 노드와 그 게임/스테이지 배정은 가능하면 그대로 보존하여 기존 진행 저장과 충돌하지 않도록 합니다.
- 추가 노드는 기존 **빈 노드**만 훈련으로 바꾸고, 경기·대회·휴식·상점·이벤트·분기 노드는 유지합니다.
