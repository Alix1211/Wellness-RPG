# 정리 문서 R33 ~ R43 (2026-10-21)

케인님 확인용. 한 일 / 남은 일 / 케인님 확인이 필요한 것 순서입니다.

## 1. 한 일

| 판 | 내용 |
|---|---|
| R32~R33 | 매점·기구방을 걸어 다니는 방으로 만들고, 방마다 말 거는 인물 배치 |
| R34 | 대사 1~5권 1차 반영: 방 담당, 이야기 24편, 게임 결과, 단계 선택 |
| R35 | 대사 반영 1단계 완료(거리 남성 거친 말, 화장실 훈련방 담당 조정) |
| R36 | 남성 초상화·거리 포즈를 원본 해상도로 교체, 방 대사는 담당 인물만 |
| R37 | 센터·회사 40개 방 전부 걸어 다니는 방, 방마다 담당 인물(초상화+SD) |
| R38 | 얼굴 있는 여성 유리·지안·오 부장 시트 초상화·SD 연결, 나가기 눌러도 방에 머묾 |
| R39 | 오 부장 SD를 시뮬레이터 에셋(기어가기·오피스 서기·합장)으로 교체 |
| R40 | 방·장소에 안 맞는 대사 걸러냄(매점·단체방·센터/회사 구분), 회사 배팅 담당 이름 |
| R41 | 담당 대사가 없는 방(화장실)에서 옛 도윤 로비 대사가 나오던 문제 차단 |
| R42 | 거리 행인(서 있는 얼굴 없는 NPC 7명) 건물 옆 배치, 거리 건물 말풍선의 센터 로비 대사 제거 |
| R43 | 얼굴 없는 NPC 22명을 센터·회사 복도와 거리에 장식 배치(서 있기 14 + 기어가기 여성 8) |

확정된 것(다시 묻지 않음)
- 얼굴 있는 여성 4명: 갈색 긴 웨이브 = 주인공, 노란 포니테일 = 유리, 검정 단발 = 지안, 올린머리 = 오 부장. 3인방 = 유리·지안·오 부장.
- 인물·초상화·SD·방 배정은 `docs/gaia/CAST_MAP.md`가 기준입니다. 새 이름은 만들지 않습니다.
- 얼굴 없는 NPC는 장식이고 말하지 않습니다. 빨강 방망이 트레이닝복은 거리 이벤트용이라 행인에서 제외했습니다.

## 2. 남은 일

단계별
- **2단계 퀘스트:** `QUESTS_DRAFT_1.md`의 Q1~Q40을 게임 퀘스트 형식으로 옮기기.
- **3단계 집·귀가:** 집 방문, 같이 귀가, 3인방 동거 장면(5권 A/B).
- **4단계 확장:** 남은 방 조연·걸어 다니는 조연, 검증.

연결 안 된 것
- 화장실 훈련방 6곳: 담당 조교·전용 대사 없음(지금은 말풍선 없이 바로 메뉴).
- 오 부장의 "남신입" 대사(초상화 없음), 건우: 연결 안 됨.
- 대사 붙을 자리: 게임 시작, 구매·서비스, 입퇴장 인사, 체력 0, 퀘스트 재촉·취소, 짝맞추기·바닥밀기·배팅머신 결과.
- 거리 이벤트용 빨강 방망이 인물 연결.
- 안드로이드 빌드(폰 폴더 mp4), 실린더 업그레이드·은퇴, 영상 보상 미니게임, 카드 게임(보류).

## 3. 케인님 확인이 필요한 것

1. **휴대폰 확인(R33~R43):** 걸어 다니는 방, 초상화, 거리 이벤트 크기, 오 부장 합장 자세, 복도·거리 배경 인물 겹침.
2. **화장실 훈련방:** 담당 조교와 전용 대사를 넣을지. 센터 남자 조교(트레이닝복 계열)는 R43 시트로 쓸 수 있고, 대사는 문서에 없어서 정해 주셔야 합니다.
3. **임시 이름:** 야간반 조교, 남신입 → 정식 이름 확정 필요. 지안의 남성 이름 충돌도 정리 필요.
4. **결혼 퀘스트 F1~F4:** 처리 방식.
5. **오 부장 표현:** 합장 자세 유지 여부, 필요하면 시뮬레이터 표정 시트로 초상화 교체.
6. **남성 초상화 업스케일:** 더 큰 원본이 있으면 교체(저장소 시트 1672×941이 현재 가장 큽니다).
