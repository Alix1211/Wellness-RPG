# 미니게임 모듈 공통 지시서

이 지시서는 GAIA LIFE에 나중에 끼워 넣을 미니게임을 따로 만들 때 적용하는 공통 규칙입니다. 각 게임의 규칙은 별도 기획안(`01-짝맞추기.md`, `02-바닥밀기.md`)을 따릅니다.

## 1. 만드는 것
- 단독으로 열리는 **HTML 파일 1개** (예: `minigame-memory-match.html`). 인터넷 연결 없이 열려야 합니다.
- 이 파일 하나만 만듭니다. **본체 게임 파일(GAIA-LIFE-*.html)은 열거나 고치지 않습니다.** 합치기는 별도 작업입니다.

## 2. 하지 않는 것
- 저장 기능(localStorage, IndexedDB, 서버)을 만들지 않습니다. 기록·골드·스탯은 본체가 처리합니다.
- 배경음·효과음을 만들지 않습니다. 이 기획안의 게임은 **무음**입니다. 소리가 필요한 자리에는 `sfx` 신호만 보냅니다(5항).
- 로그인, 광고, 결제, 외부 링크, 외부 CDN을 쓰지 않습니다.
- 성적인 행위를 직접 묘사하는 문구를 쓰지 않습니다. 말투는 밝은 코미디입니다. 남자는 반말, 여자는 남자에게 존댓말입니다.

## 3. 화면
- 세로 화면 스마트폰(412×850 기준) 터치 조작. 가로 스크롤이 생기면 안 됩니다.
- 터치로 누르는 곳은 가로·세로 48px 이상.
- 글자는 한국어. 처음 화면에 한 줄 설명과 "시작" 버튼, 끝나면 결과와 "다시 하기"·"닫기" 버튼.
- 그림이 없을 때도 열려야 합니다. 그림 설정이 비어 있으면 단색 도형과 글자로 대신 보여 줍니다.

## 4. 본체가 넘겨주는 설정
파일 맨 위에서 `window.GAME_CONFIG`를 읽고, 없는 값은 아래 기본값으로 채웁니다.

```js
const CFG = Object.assign({
  roomId: 'test',        // 본체가 넘기는 방 식별자 (그대로 결과에 되돌려 보냄)
  kind: 'memory',        // 게임 종류 이름
  difficulty: 1,         // 1 쉬움, 2 보통, 3 어려움
  location: 'street',    // 'home' | 'street' | 'center' | 'company'
  goal: null,            // 성공 기준 점수(없으면 게임별 기본값)
  images: [],            // 그림 주소 목록 (URL 또는 data URI)
  lines: {}              // 장면별 대사 (본체가 채움, 없으면 기본 문구)
}, window.GAME_CONFIG || {});
```

## 5. 본체에 보내는 신호
끝날 때 한 번 결과를, 닫을 때 닫힘을 보냅니다. 현재 게임 안의 다른 미니게임이 쓰는 것과 같은 이름입니다.

```js
// 결과
parent.postMessage({
  type: 'wellness-result',
  roomId: CFG.roomId, kind: CFG.kind,
  score: 0,            // 정수 점수
  ratio: 0.0,          // 0~1 달성률
  success: true,       // 성공 여부
  detail: '요약 문구'   // 한 줄 설명
}, '*');
// 닫기 ("닫기" 버튼을 눌렀을 때)
parent.postMessage({ type: 'wellness-close' }, '*');
// (선택) 소리 신호: 이름만 보내고 소리는 만들지 않음
parent.postMessage({ type: 'wellness-sfx', name: 'success' }, '*');
```

단독으로 열렸을 때(`parent === window`)는 위 신호를 화면 구석에 작게 글자로 보여 주기만 합니다.

## 6. 품질 기준
- 크롬(안드로이드)에서 60fps 가까이, 한 판 1~2분 이내.
- HTML 파일 크기는 그림 제외 300KB 이하.
- 한 판을 끝까지 하고 "다시 하기"를 연속 20회 해도 느려지거나 멈추지 않을 것.
- 설정 없이(단독으로) 열어서 처음부터 끝까지 플레이할 수 있을 것.

## 7. 납품물
1. HTML 파일 1개
2. 사용한 설정 값과 기본값을 적은 짧은 설명(10줄 이내)
3. 직접 해 본 것(어떤 화면 크기에서 몇 번 플레이했는지) 한 줄
