# Character assets

User-provided source PNGs live in [`characters/portraits/`](characters/portraits/). All ten files retain their original filenames and bytes.

- `jeans/`: two numbered 2×2 sheets plus two earlier pose-sheet variants.
- `office/`: two numbered 2×2 sheets.
- `lavender-yoga/`: two numbered 2×2 sheets.
- `adult-nude/`: one temporary nude 2×2 portrait pending a later user-supplied upscaled version.
- `swimwear/`: one reaction sheet.

For the numbered outfits, the first sheet's four expressions are the main dialogue set; the second sheet is for secondary reactions. Hair/edge cleanup is pending on some files. The four-legged movement and jump sheets requested for the game were not retrievable with the conversation attachments, so no movement/jump PNGs are present yet.

Keep the separate private photo/video gallery pack under ignored local paths such as `assets/local/`. Check [`HANDOFF.md`](../HANDOFF.md) before publishing or using adult art.
