# Assets

No image assets are committed in this setup.

- Put user-imported ZIP packs and their extracted contents under `assets/local/`. This path and common archive formats are ignored by Git.
- Reserve a future `assets/public/` path for assets that have been individually reviewed for rights and suitability.
- Never commit adult images to GitHub.
- Keep costume sprite metadata/manifests in source control only after the import format is agreed; keep private image files local.

Before any later asset commit, review the staged file list and image contents.
