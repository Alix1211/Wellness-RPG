## 2. 작업 범위와 원칙

- 사용자의 지시: **캐릭터 이미지 생성·변경은 보류하고 미니게임 배경판 두 장만 적용**.
- 가로와 세로는 크기만 연동하는 한 이미지가 아닌 **서로 다른 실제 PNG 두 장**을 사용.
- 게임 규칙·조작·기존 캐릭터·기존 애니메이션과 오디오는 수정 대상에서 제외.
- 탁구 경기장 관중석과 시작화면 로고는 기존 v12.7 배치를 그대로 유지.
- 새로운 ZIP/버전을 제작해 예전 v12.7 배포본을 덮어쓰지 않음.

## 3. v12.8 미니게임 배경판 교체

| 화면 방향 | 적용 원본 | 원본 픽셀 |
| --- | --- | --- |
| 가로 landscape | `핑크 민트 핑퐁 체육관-1.png` | 1672 × 941 |
| 세로 portrait | `아기자기한 핑크 민트 탁구장-2.png` | 941 × 1672 |

- 화면 방향 판단: `innerHeight > innerWidth`이면 세로, 아니면 가로.
- 크기 조절: `cover` 방식. 원본 종횡비를 유지하면서 화면을 채우며 중앙 기준 일부가 잘릴 수 있음. 이미지 **찌그러짐 없음**.
- 회전/크기 변경: `resize`, `orientationchange`에서 선택 배경을 갱신.
- 미니게임별 기존 IndexedDB 저장 정보(캐릭터, 편집, 사운드 등)는 보존. 단, **가로/세로 배경 슬롯은 신규 이미지로 고정**.
- 해당 이미지는 각 미니게임의 `CASUAL_MEDIA_RECORD.layout.portrait.background`와 `.landscape.background`에서 사용.
- 원본 PNG 파일은 게임 내부에 내장되지만, 미리보기와 이미지 바이트 동일성을 테스트할 수 있도록 빌드 원본은 작업 공간의 `upload` 폴더에 보유.

### 적용된 8종

1. **움찔 찾기** (`wiggle`)
2. **뒤를 조심!** (`behind`)
3. **균형 맞추기** (`balance`)
4. **스쿼트** (`squat`)
5. **실린더** (`cylinder`)
6. **백만대 챌린지** (`tap`)
7. **컨베이어 배팅** (`batting`)
8. **물어와!** (`fetch`)

각 게임은 1~10단계의 구분 데이터가 있고, 미니게임 진입 때 같은 배경 어댑터를 적용합니다.

### 렌더링 방식이 다른 게임 처리

- `wiggle`, `behind`, `balance`, `tap`: DOM의 `.mg-scene`에 별도 방향별 배경 지정.
- `fetch`: 움직이는 바닥/장애물/캐릭터를 계속 그리되, 기존 불투명 원경 대신 새 배경이 보이도록 `MEDIA_BACKGROUND` 설정.
- `squat`, `batting`: 캔버스의 `CasualCanvasBackground` 훅에서 새 배경을 **캐릭터 아래에** 렌더링. 캐릭터와 입력 위치는 변경하지 않음.
- `cylinder`: 기존 코드가 `<head>`와 `</head>`를 명시하지 않는 특수 HTML 구조였기 때문에, 해당 게임에는 독립된 head 주입 경로를 추가. 캔버스 배경을 투명화하고 CSS 배경을 보이도록 설정.
- `POOL`과 `DOCS`에 내장된 게임 본체 코드는 v12.7과 **동일한 문자열**로 검증. 새 코드가 추가된 곳은 훈련용 래퍼의 진입 시 설정 영역뿐.

## 4. 앞선 v12.7 작업 — 이번 버전에서도 유지

### 스쿼트 사운드 관련

- 스쿼트의 음악과 박자음은 원래 **90 / 120 / 150 BPM별 2파일씩, 총 6개 OGG**가 있었음.
- v12.7에서 파일은 바꾸지 않고 재생 음량만 조정. 음악 gain은 난이도별 2.1 / 1.45 / 1.35, 박자 gain은 10.5 / 6.25 / 4.3.
- iframe에서 코드가 강제로 누르던 자동 `시작`을 제거하고, 스쿼트의 실제 화면 **시작 버튼 한 번 터치**로 WebAudio 잠금이 해제되도록 변경.
- 이 수치는 코드상 변경 사항이지 Android 기기에서 충분히 잘 들린다는 실기 검증 결과는 아님.

### 시작화면 로고와 관중석

- 타이틀 로고 흔들림 키프레임 안에서 `translateX(-50%)` 누락으로 중앙에서 벗어나던 문제 보정.
- 로고 세로: 화면 중앙 기준 상단, 너비 `min(76vw,520px)`.
- 로고 가로: 화면 너비 약 78% 위치의 상단, 너비 `min(32vw,465px)`.
- 탁구장 관중석: 가로·세로 각각 폭/높이 계산을 분리하여 가로화면의 과도한 확대를 줄임.
- **v12.8에서는 이 로고·관중석 코드를 추가로 수정하지 않음.**

## 6. 알려진 위험 / 다음 확인 순서

1. ZIP에서 두 HTML을 같은 폴더에 둔 뒤 실행. 미니게임 하나를 열어 배경이 보이는지 확인.
2. 세로에서 **움찔 찾기**, **스쿼트**, **물어와!** 확인. 특히 움직이는 바닥과 배경 겹침 체크.
3. 기기를 가로로 돌려 세로 이미지가 아니라 **가로 이미지**가 표시되는지 확인.
4. 가로에서 **실린더**, **배팅**, **균형 맞추기** 확인. 게임 영역의 불투명 캔버스 또는 배경 덮임 체크.
5. 스쿼트는 직접 시작 버튼을 누른 뒤 **90 / 120 / 150 BPM의 음악과 박자음 모두 실제 청취**.
6. 메인 경기 관중석과 시작화면 로고가 v12.7에서 변경되지 않았는지 양방향에서 비교.
