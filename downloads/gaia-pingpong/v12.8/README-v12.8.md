# GAIA PINGPONG v12.8 — 미니게임 가로/세로 배경판 교체

## 실행

1. ZIP 압축을 풉니다.
2. `GAIA-Pingpong-v12.8-Minigame-Backgrounds.html`을 실행합니다.
3. `GAIA-Pingpong-v12.8-Training.html`을 **같은 폴더**에 둡니다. 미니게임 실행 시 이 파일을 불러옵니다.

전체 코드 변경 및 검증 내역은 함께 포함된 **`GAIA-Pingpong-v12.8-HANDOFF.md`**를 참조하세요.

## 이번 수정 범위

- 가로 배경: 사용자가 제공한 **핑크 민트 핑퐁 체육관-1.png** (1672 × 941).
- 세로 배경: 사용자가 제공한 **아기자기한 핑크 민트 탁구장-2.png** (941 × 1672).
- 미니게임 8종 **움찔 찾기, 뒤를 조심!, 균형 맞추기, 스쿼트, 실린더, 백만 대, 컨베이어 배팅, 물어와!**에 공통 적용.
- 화면 방향에 따라 각각 다른 원본을 선택합니다. 이미지 확대/축소는 중심을 기준으로 **비율 유지 + 영역 채우기(`cover`)** 방식입니다. 찌그러뜨리거나 다른 방향 이미지를 늘려 쓰지 않습니다.
- 스쿼트와 배팅은 캔버스의 캐릭터·게임 동작 아래에 배경을 그립니다. 물어와!의 진행용 이동 바닥은 기존대로 유지합니다.
- 이전에 사용자가 저장한 캐릭터·효과음·입력 설정 및 원래 스쿼트의 90/120/150 BPM 음악/비트 설정을 유지합니다.
- 가로/세로 편집용 미니게임 배경 슬롯만 이번 배경으로 갱신합니다.
