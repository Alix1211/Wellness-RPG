# GAIA PINGPONG CHAMPION — v12.11 핫픽스 패치 (2026-10-24)

이 압축파일에는 **변경 파일 4개만** 포함되어 있습니다. 기존 v12.11 게임 데이터(이미지, 음향, 에셋)는 포함하지 않았습니다.

## 적용 방법

1. 기존 `GAIA-v12.11-1.zip`, `GAIA-v12.11-2.zip`, `GAIA-v12.11-3.zip`을 **같은 폴더에** 이미 압축 해제한 상태에서 시작합니다.
2. 이번 패치 ZIP도 **그 폴더에** 압축을 해제합니다.
3. `GAIA-Pingpong-v12.11.html`과 `source/` 아래 같은 이름의 파일을 **덮어쓰기** 합니다.
4. 기존 `assets/` 폴더는 그대로 둡니다. 게임은 `GAIA-Pingpong-v12.11.html`을 엽니다.

**주의:** 세 묶음의 원본 ZIP 중 일부가 빠져 있으면 이미지·사운드 등이 표시되지 않습니다. 이번 패치만 단독 실행하는 형태는 아닙니다.

## 수정 내역

1. **월드투어 지도 및 카드 선택:** 이동 카드 클릭 시 지도 전체를 다시 그리지 않고 도착 가능한 노드와 선택 카드 표시만 갱신합니다. 지도 화면의 강제 스크롤과 반복 재정렬을 줄이고, 실제 노드 이동 때만 위치를 새로 맞춥니다. 선택 취소도 지도 재생성 없이 작동합니다.
2. **미니게임 일시정지 버튼:** 점수판을 가리던 큰 `일시정지` 문구를 없앴습니다. 미니게임에서 왼쪽 아래 작고 반투명한 `Ⅱ` 버튼을 눌러 기존 일시정지·종료 메뉴는 사용할 수 있습니다. 탁구 경기의 별도 버튼 배치는 변경하지 않았습니다.
3. **리듬 실린더 그림 변경:** 원래 구현되어 있었으나 공통 CSS에 숨겨졌던 `그림 변경` 버튼을 다시 보이게 했습니다. 중앙 이미지와 `배경판` 항목을 선택해 사용자 이미지를 적용하고 복원할 수 있도록 했습니다.
4. **미니게임 시작 화면:** `물어와!`와 `컨베이어 배팅` 진입 직후 난이도·의상 선택창이 순간 보이는 현상을 줄이도록, 자동 시작이 처리될 때까지 내부 화면을 가렸다가 표시합니다. 정상 시작이 지연될 때에는 일정 시간 후 표시합니다.

## 변경하지 않은 항목

- 상대 선수의 스킬 수비/방어 확률: 사용자 요청에 따라 현 상태 유지.
- 원본 캐릭터 이미지 및 크기·배치.
- 가로·세로 미니게임 배경 이미지와 기존 별도 레이아웃: 이전 v12.11 기준 유지. 이번 수정으로 강제 공통 비율을 추가하지 않았습니다.
- 경기 규칙, 경험치, 카드 소모, 월드투어 해금 및 기록, 세이브 포맷.
