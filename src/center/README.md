# 센터 실내 이동 구현

2026-10-17 KST. 기존 Wellness는 읽기만 했고 이 구현은 Wellness-RPG 전용이다.

## 실행

루트 index.html은 필요한 코드·그림·미니게임 에셋을 내장한 단일 오프라인 HTML이다. 다운로드 후 Chrome에서 연다. 바닥 터치/조이스틱/방향키/WASD로 이동하고 열린 입구를 누르거나 E/Enter/오른쪽 버튼으로 상호작용한다. Space/화살표 버튼으로 점프한다. 세로 화면은 캐릭터 추적 카메라, 가로 화면은 넓은 공간을 보여준다. 상단 복장 버튼에서 센터복/오피스룩/캐주얼을 선택한다.

## 미니게임과 서비스 범위

기초방=물어와, 단체방=움찔 찾기, 자세 점검방=균형 맞추기, 체벌방=백만 대/뒤를 조심을 연결했다. 소시지는 회사/침실용이므로 센터 방에 임의 배치하지 않았으며 공통 호스트에서 실행 검증만 했다. 각 게임은 iframe 안에서 원본 호스트를 격리해 실행한다. 원본 전역 저장/회원 성장/시간/팁 기능은 RPG 상태에 연결하지 않는다. 게임 결과 중 최고 기록만 로컬에 보존한다.

기구방의 줄 자르기와 화장실의 물병 채우기는 미구현이며 해당 방은 출입·안내만 가능하다. 회복방은 쉬기 동작을 연결했고 체력/마조력 감소 규칙은 없다. 매점은 진열 확인까지만 가능하며 구매·가격·아이템 효과는 미연결이다. NPC는 담당자를 나타내는 임시 실루엣이며 기존 대사집과 주인공 대화 초상화는 아직 연결하지 않았다. 회사/본인 집/드림하우스는 이 구현 범위가 아니다.

## 주인공 애니메이션 수정 v2

- 기존의 프레임별 전체 높이 강제 정규화를 제거했다. 모든 프레임은 224×208 투명 캔버스와 (112,190) 발 기준점을 공유한다. 머리 폭 기준을 74px로 맞춰 방향/복장/점프 포즈에 따른 신체 크기 팽창을 줄였다. 이동 깊이에 따른 크기 변화도 제거했다.
- 원본 시트의 분리된 알파 점과 주변 색 잡음을 제거한 파생 프레임을 추출했다. 4×2 시트의 점프 머리가 행 경계에서 잘리던 문제를 막기 위해 실제 동작 사이 여백을 경계로 사용했다. 원본 PNG는 수정하지 않았다.
- 점프 버튼은 pointerdown 시 즉시 작동한다. 스틱과 점프는 서로 다른 손가락 ID를 유지한다. 점프 손가락을 떼어도 스틱 입력이 취소되지 않는다.
- 이동 중 점프는 이륙 방향의 이동량을 유지한다. 한 손가락으로 스틱을 놓고 즉시 점프할 때는 0.18초 이내의 이동 방향을 이어받는다. 제자리에서 시작하면 수평 이동이 없다. 점프 방향 포즈는 착지까지 유지하고 착지 후 방향 전환한다.
- 공중에서 방 출입 목표에 도착해도 착지 전에는 화면을 전환하지 않는다.
- 원본 시트를 교체하면 python src/center/prepare_sprites.py 후 python src/center/build.py로 다시 만든다. 추출에는 Pillow/NumPy/SciPy가 필요하다. sprite-alignment.json은 크기/기준점/원본 셀/정규화 정보를 보존한다.
- 검증: 72프레임의 동일 캔버스/기준점/머리 기준, 5방향 이동 점프, 정지 점프, 착지 검사 통과. 실제 Chrome CDP 터치로 두 손가락 이동+점프와 점프 손가락 독립 해제, 한 손가락 전환 점프, 세 복장과 세로 화면 렌더 검사 통과. pageerror 0건. Android 실기기 확인은 남아 있다.

## 2026-10-17 복도 액자 · 생활 인물 v3

- 각 층의 엘리베이터 옆과 방 사이 벽면에 액자를 배치했다. 기본 그림은 코드로 그린 풍경이다. 액자를 터치하거나 상단 ▧ 버튼 → 액자 선택 → 사진 변경으로 교체한다. 기본 그림 복원도 가능하다.
- 선택한 사진은 긴 변 1600px 이하 JPEG로 변환하여 액자 ID별 IndexedDB에 저장한다. 같은 기기/브라우저/문서 주소에서 재실행 시 유지한다. 서버 전송·GitHub 업로드·기기간 동기화는 하지 않는다. 저장 불가 시 성공으로 표시하지 않고 오류를 알린다.
- 사용자 PNG 14장을 원본 그대로 assets/characters/npcs/source/에 보존했다. 주인공 화면 캡처 JPG는 제외했다. 57개 외형/148개 프레임을 추출해 내장했다. 정장·평상복 남성도 방문객/로비 안내에 활용한다. 회사/길거리 맵은 새로 만들지 않았다.
- 불규칙한 시트를 정사각 격자로 자르지 않는다. 연결된 인물 경계를 검출하고 각 행의 좌우 순서로 배정한다. 요가복 시트의 붙어 있는 두 인물은 본체 마스크를 기준으로 분리한다. 시퀀스 안에서는 크기를 고정하고 바닥 기준점을 공유한다. 원본 가장자리에서 이미 잘린 부분은 복원하지 않는다.
- 여성의 측면 4+4컷은 이동·짧은 점프, 전후 4×4컷은 앞뒤 이동·자세 전환으로 연결했다. 6×2 시트는 같은 열의 두 자세만 연결하며 서로 다른 인물을 애니메이션 프레임으로 취급하지 않는다.
- 남성은 걷기 프레임이 없으므로 제자리에서 방향 전환·기울이기·짧은 인사를 한다. 이동 프레임 없이 미끄러져 이동시키지 않는다. 각 인물의 동작/휴식 시간은 독립적이다. 활성 공간만 업데이트하며 대화창·미니게임 중에는 멈춘다. 인물/주인공은 발 위치로 앞뒤 순서를 정한다.
- 소스: life.js, gallery.js, prepare_npcs.py, npc-manifest.json, npc-assets.json. 재생성: python src/center/prepare_npcs.py 후 python src/center/build.py.
- 검증: 6개 복도+26개 방의 인물 경계, 14장 사용, 148프레임, 이동/인사/자세 전환/점프 확인. 실제 Chrome 액자 터치·파일 선택·재실행 유지·기본 복원 유지·가로/세로 버튼 확인. 기존 이동 중 점프·두 손가락 독립 조작·세 복장 검사 통과. Android 실기기 성능은 사용자 확인 필요.
