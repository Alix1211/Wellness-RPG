# 세 미니게임 · 정사각 프레임

2026-10-17 사용자 확정 기획에 따른 v6. 이미지 선택은 사용자 담당이며 모든 판정은 그림과 분리되어 있다.

| 게임 | 위치 | 조작 / 판정 |
| --- | --- | --- |
| 물병 채우기 | 센터·회사·집 화장실 | 2×2 정사각 그림, 그림마다 독립 게이지 1개(총4개). 입구는 각 그림 정중앙(50%,50%). 하단 중앙 물총, 화면을 누른 채 좌우·앞뒤 이동으로 조준과 거리 조절. 발사 버튼과 각도/파워 슬라이더 없음. 손을 떼면 발사 중지. |
| 줄 자르기 | 센터 기구방 | 줄을 가로질러 스와이프. 구슬은 중력과 줄의 장력·관성으로 이동. 하단 정중앙 목표 x=360,y=650. 6단계, 재도전/다음 단계. 떨어져 빗나가면 실패. 자동 시간 제한 없음. |
| 리듬 실린더 | 회사 공용 사무실·집 거실 | 중앙 이미지와 고정된 세 하트 발생점. 이미지 연타로 측면 게이지 상승, 손을 떼면 하강. 초과 눈금82. 랜덤 하트 터치로 포인트·핑크 안개·하트 입자·3곳 불꽃놀이. 리듬 터치와 하트 터치에 기존 7개 음원 재사용. |

## 기본 수치 (코드에서 조정 가능)

- 물병: 45초, 병당100, 총400점. 시간 종료 시 총 충전량 평가. 흐름11/초. 물통 제한/흘린 물보다 더 받아야 성공하는 v5 규칙은 폐기.
- 물병 입구: 720×720 안의 각 250×250 그림 중심, 반지름19. 그림 위치/정중앙 좌표는 `models.js` TILES에서 고정. 물줄기는 목표 거리별 비행시간과 중력700을 적용한 입자 궤적. 입자가 도착한 지점이 입구 안이면 충전한다. 이미지 몸통은 별도 충돌체가 아니다.
- 실린더: 60초, 목표1000. 연타+9, 초당−19, 안정구간32~72, 초과82. 안정구간의 연타+3, 구간 유지+5/초. 하트는 안정구간+45, 밖에서는+10. 초과 시−45/0.7초 쿨다운. 연타 없이 하트만 치거나 무작정 초고속 연타하는 우회로를 제한한다. 세 지점에서 0.7~1.25초 간격으로 출현, 수명1.65초.
- 줄 자르기: `models.js` LEVELS에 구슬/앵커/장애물. 1/120초 이하 분할 적분. 성공 경로는 모델 테스트로 확인했다. 복수 줄 단계는 먼저 일부를 자르고 흔들림에 맞춰 나머지를 자른다.
- 시간과 목표 점수의 구체 숫자는 구현 기본값이며 사용자 확정 고정값은 아니다. `GAME_CONFIG.water.duration`, `GAME_CONFIG.cylinder.duration/goal` 또는 모델 생성자 기본값으로 조절한다.

## 이미지·음원

게임 아래 `그림 변경`에서 물병 그림1~4·물총·구슬·실린더 중앙 이미지·각 게임 배경을 바꿀 수 있다. 긴변1600px, 투명 PNG 유지. 그림별 IndexedDB 저장/기본 복원. 사진은 업로드/전송/커밋하지 않는다. 같은 브라우저의 같은 문서 주소에서 유지한다. 입구 판정은 그림 교체로 바뀌지 않는다. 하트 좌표는 Cylinder.points에서 조정한다.

통합 호스트는 기존 `미니게임/audio/01.ogg`~`07.ogg`를 전달한다. Web Audio로 첫 시작/터치에서 준비한다. 리듬 연타마다 재생 이벤트를 발생시키며 동시 음원은3개로 제한한다. 정지·초점 이탈·종료 때 입력/소리를 정리한다. 줄 절단은 짧은 찰싹 계열 합성 타격음. 외부 음원 호출 없음.

## 빌드·검증

- `python src/minigames/life-suite/build.py`: 3개 단독 HTML (단독판에는 외부 음원 미포함).
- `python src/center/build.py`: 기존 게임·인물·센터·회사·집을 포함한 단일 오프라인 HTML.
- `node tools/test_life_models.cjs`: 20/30/60/120fps 물병 조준·총량 보존·빗나감, 실린더 리듬 성공/과잉 연타/하트만 치는 우회, 줄 6단계 실제 스와이프 교차 판정과 성공 경로.
- `CHROME_BIN=... node tools/test_life_integration.cjs`: 전체55장면, 집 양방향 끝 전환, 게임 입력·방 매칭·일시정지·세로 화면.
- `CHROME_BIN=... node tools/test_life_persistence.cjs`: 실제 CDP 터치 발사/해제와 2포인터 하트+리듬 입력, 7음원 디코드/재생/정지, 이미지 업로드/재진입/복원, 집 배경과 방문방 저장, 점수 저장.

새 성장/경제/취업/결혼 조건은 이 작업에 포함하지 않는다. 새 게임 결과는 기존 최고기록 체계의 kind6/7/8에 기록한다.
