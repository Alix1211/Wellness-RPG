# GAIA CITY: DETECTIVE — 전체 지역 배치 시험판

2026-10-26. 마지막 뒷골목·클럽 소스(version5)에 확장분을 복원한 판입니다. 기존 카드게임은 별도로 보존합니다. 기존 도시 지도·버튼·로지 조작·기본 공격·바디스플래시·두 스킬·공통 적 연출을 유지합니다.

## 실행

실행 파일 `GAIA_Detective_All_Stages.html`을 브라우저에서 여십시오. 이미지와 음원이 내장돼 있어 네트워크 없이 실행됩니다. 이 소스의 `index.html`은 `python -m http.server 8000`으로 열 수 있습니다. `python build_portable.py`로 동일한 단일 HTML을 만듭니다.

도시 지도 아이콘 → 장소 선택 → 01/02 출동 → 전투 → 결과 또는 일시정지에서 지도 복귀. 같은 지역 01을 마치면 02가 열립니다. 새 지역 01은 시험을 위해 바로 선택 가능합니다. 경찰서에서 HP/M파워를 회복합니다.

카지노는 보스 설정이 정해지지 않아 이번 확장에 포함하지 않았습니다. 전체 스토리·대사집, 통합 인벤토리·장비·스탯·카드 50종은 이번 범위에 포함하지 않습니다.

일반 몹은 공통 12종을 지역을 가리지 않고 혼합합니다. 새 일반 경로는 전진 전투 18개와 마지막 보스 구역 1개로 구성했습니다. 보통 구역마다 적 두 무리가 순차 등장합니다. 지역 02는 두 번째 배경을 사용하고, 보스 구역에서는 기존 카드게임 장소 배경으로 전환합니다. 공원은 12개 구역이며 세 구역마다 보스가 섞이고 완료 횟수에 따라 조합·배치가 달라집니다.

## 이미지와 종이인형 애니메이션

사용자가 다시 첨부한 기존 보스 시트 4장을 사용했습니다. 이번에 추가 생성된 대체 시트는 게임에 사용하지 않았습니다. 새 보스 12명, 분리한 자세 20장. 8명은 기본/공격 2장, 사수 4명은 각각 1장입니다. 원본 시트는 `art-source/`에 보존했습니다. 분리본과 배경은 `assets/regions/`에 있습니다.

알파 성분별로 인물을 추출해 인접 인물 조각을 제외했습니다. 같은 인물의 두 자세는 같은 캔버스 크기·높이 기준을 사용하며, 발 중심을 캔버스 중앙과 공통 바닥선에 맞췄습니다. `art-source/alignment.json`에 원본 성분과 크기를 기록했습니다. 종이인형 전체 그림의 이동·기울임·자세 교체와 기존 피격·넉백·퇴장을 사용합니다. 팔다리를 개별로 움직이는 애니메이션은 아닙니다.

여성 투척은 기존 여성 악당 이미지를 포물선으로 이동·회전시키고 잠깐 바닥에 남겼다 제거하는 방식입니다. 복잡한 표정·몸부림·기상 연기는 추가하지 않았습니다. 거부된 로지 회전킥 시트는 사용하지 않습니다.

## 조작·초기 난이도·저장

화면 버튼은 아래 점프, 왼쪽 가슴, 위 엉덩이, 오른쪽 방어. 키보드는 방향키/WASD 이동, J 가슴, K 엉덩이, Space 점프, Shift 방어, Q 하트, E 누름/해제로 충격 저장입니다.

로지 HP160/M100은 그대로입니다. 일반 적 체력은 농장×1.04, 호텔×1.08, 촬영소×1.10, 환락가×1.14의 지역 고정 배율입니다. 플레이어 성장에 맞춘 자동 강화는 없습니다. 보스 체력·공격 예고·간격·선호 거리는 종류마다 별도입니다. 공원 보스 체력은 원형의60%입니다. 부하 호출은 생존 적 7명 미만일 때만 2명 추가합니다.

새 보스 HP: 연구소장290, 농장주470, 마피아4명125/150/120/140, 호텔 보스560, 감독330, 미녀290, 호스트510, 업주430, 미남650. 목표는 일반 경로당5~8분이며 확정 밸런스가 아닙니다. 이전 구현의 무적 자동 조작 기록은 약336~361초, 공원 약208초였습니다. 실제 태블릿 생존 밸런스·성능·수동 플레이 시간은 미검수입니다.

저장 키 `gaia_detective_alley_campaign_v1`, version1을 유지합니다. 이전 골드·완료 기록·체력·체포·체크포인트를 읽고 stage5~13과 eventRuns를 추가합니다. 원본 카드게임 저장에는 접근하지 않습니다. 4구역마다 체크포인트, 패배 후 재도전, 경찰서 회복을 연결했습니다.
