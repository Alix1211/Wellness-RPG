# 소시지 합치기 · 16:9 가로형 성능 시험

이 폴더는 **미니게임 한 종류만** 시험합니다. 본편 RPG의 화면 비율이나 챕터 설계를 변경하지 않습니다.

## 선정 근거

원본 Wellness의 `main` 코드(`minigames.js`, `minigame_behind.js`, `fetch-game.js`)와 `미니게임/` 에셋 목록을 확인했습니다.

| 미니게임 | 실제 갱신·그리기 경로 |
| --- | --- |
| 움찔 찾기 | 9개 DOM 이미지에 CSS 애니메이션을 적용하고 타이머·점수를 rAF마다 갱신 |
| 소시지 합치기 | **Matter.js를 120Hz 고정 간격으로 갱신**하고, 복합 물리 몸체(사각형 1개+원 2개씩)의 충돌을 처리하며, 1280×1020 캔버스를 매 프레임 다시 그림 |
| 아슬아슬 균형 잡기 | 1440×960 캔버스를 매 프레임 다시 그리지만 물리 계산은 몇 개의 스칼라 값 |
| 백만 대 챌린지 | DOM 배우 3명과 게이지를 rAF마다 갱신 |
| 뒤를 조심!! | 1440×960 캔버스와 120Hz 투사체 계산. 투사체·대상 수가 제한적 |
| 물어와! | 1920×1080 캔버스에 배경 타일·달리기 프레임·장애물을 매 프레임 그림. 화면 픽셀 부하는 크지만 물리 엔진과 동적 충돌 몸체가 없음 |

따라서 **CPU 계산과 렌더링을 함께 누르는 단일 시험 대상으로 소시지 합치기**를 골랐습니다. 이는 코드 경로에 근거한 선정이며, 실제 기기에서 여섯 게임을 벤치마크해 순위를 확정했다는 뜻은 아닙니다.

## 사용법

1. 저장소 루트에서 정적 웹 서버를 실행합니다. Windows에 Python Launcher가 있으면 `py -m http.server 8000 --bind 0.0.0.0`을 사용할 수 있습니다.
2. PC에서 `http://localhost:8000/prototype/`을 엽니다.
3. Android 휴대전화와 PC를 같은 Wi-Fi에 연결합니다. PC의 IPv4 주소를 확인한 뒤 Android Chrome에서 `http://PC의-IP주소:8000/prototype/`을 엽니다. 방화벽이 묻는 경우 같은 네트워크에서의 접속을 허용해야 합니다.
4. 휴대전화를 **가로로 회전**합니다. 화면은 항상 16:9이고 남는 기기 화면은 바깥쪽에 표시됩니다. 세로 상태에서는 회전 안내가 나옵니다.
5. 먼저 기본 배경으로 `자동 투하 켬`을 눌러 FPS와 프레임 누락 수치를 봅니다. `다시 시작`을 누른 후 `내 MP4 선택`으로 기기에 있는 MP4를 고르고 같은 방식으로 비교합니다. `게임 배경 진하기`를 바꾸면 게임 판 뒤의 반투명 막만 변합니다.

영상은 브라우저의 로컬 파일 선택기로만 읽으며 업로드·저장하지 않습니다. `object-fit: cover`로 **16:9 게임 화면 전체**를 가장자리까지 채우며 비율이 다른 영상은 잘립니다. 음소거·반복 재생이고, 선택하지 않았거나 재생할 수 없으면 기본 배경이 있습니다. 일부 MP4 코덱은 Android Chrome에서 재생되지 않을 수 있습니다.

FPS는 화면 갱신 콜백을 1초 단위로 센 값입니다. 프레임 누락은 관찰된 화면 주기보다 1.5배 긴 간격을 추정해 누적합니다. 영상 누락은 Chrome이 `getVideoPlaybackQuality()`를 제공할 때만 표시합니다. 두 수치는 기기·화면 주사율·열 상태·영상 해상도에 따라 달라집니다. 설정이 같고 휴대전화가 충분히 식은 상태에서 기본 배경과 영상을 각각 여러 번 비교하세요.

## 범위와 차이

- 원본의 Matter.js 0.20.0, 중력, 충돌 몸체, 120Hz 물리 간격, 합치기 규칙과 60초 제한을 옮겼습니다. 자동 투하는 몸체 수를 빠르게 늘리는 시험 조작입니다.
- 소시지 그림 6개는 이 프로토타입에서 캔버스로 생성합니다. 원본 Wellness 이미지나 RPG의 사용자 초상화·개인 영상은 복사하지 않았습니다. 따라서 원본 이미지의 디코딩·메모리 특성은 재현하지 않습니다.
- 향후 초상화/대사 표시용 공간은 오른쪽 위에 비워 두고, 실제 조작 버튼은 왼쪽 게임 판 아래에 둡니다. 초상화·대사 시스템 자체는 구현하지 않았습니다.
- Matter.js는 MIT 라이선스이며 [라이선스](vendor/MATTER-LICENSE.txt)를 함께 둡니다.
- 이 화면은 웹 성능 시험입니다. Android APK나 본편 RPG 연결은 아직 없습니다.
