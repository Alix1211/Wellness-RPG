# iPlay 70 mini Pro 타구 진동 조정 — 게임 빌드 2026102504

사용자 실기기 보고: iPlay 70 mini Pro에서 다른 게임 진동은 정상이며, 탁구 실점의 '아얏' 진동도 정상이다. 일반 타구 진동이 체감되지 않았다. 하드웨어 미지원으로 단정하지 않는다.

기존 native 진폭 요청은 지원 기기에서 이미 255(최대)다. 이번에는 JS 요청 시간을 일반 타구 35→100ms, 미주 서브 25→80ms, 설정에서 진동 켤 때 시험 진동 30→100ms로 늘렸다. 실점 65ms와 결과 패턴, 진동 OFF, 음소거 분리, 기존 중복 호출 제한은 유지한다. 이 값이 모든 iPlay 기기에 검증된 권장값이라는 뜻은 아니다. 사용자 피드백에 따라 체감 조정한다.

변경: native-ui.js와 실제 배포 index.html의 동일 문자열 2곳. prepare_game.py는 갱신된 native-ui.js를 읽으므로 다음 빌드에도 유지된다. Android 코드는 변경 없음. 앱/세이브/장비/경기 규칙/음량/이미지/실린더 변경 없음.

v12.12.3 자동업데이트 APK에서 게임 빌드 2026102504를 내려받고 다음 Activity 시작 때 적용한다. 신규 APK 설치는 필요 없다. 이전부터 앱이 백그라운드에만 남아 있으면 시작 이벤트가 다시 발생하지 않으므로, 설정의 업데이트 확인 후 준비 완료 상태를 보고 앱을 완전히 닫고 다시 실행한다. 구형 APK에는 이 자동업데이트 기능이 없으므로 별도 설치가 필요하다.

검증: 실제 배포 ZIP을 SHA256/크기로 확인하고, 변경 2곳을 적용한 ZIP의 CRC/재조립 동일성을 확인. JS 모의 브리지에서 요청 100/80/65ms, 진동 OFF 차단, 중복 제한, 설정 시험100ms 및 실제 HTML 최상위 JS 구문을 확인. 실제 태블릿 모터 체감은 직접 검증하지 못함.
