# GAIA 스쿼트 음량·실린더 사진 변경 수정

## 기준 파일
`enemy-input/release/GAIA-Pingpong-v12.11.html` (직전 라켓 터치 수정 포함).

## 수정 범위
- 스쿼트 음악 gain: 90/120/150 BPM 각각 2.1→3.6, 1.45→3.2, 1.35→3.0.
- 같은 BPM 신음 루프 gain: 10.5→2.7, 6.25→2.1, 4.3→0.55. 별도 반응 음성과 perfect 음성도 절반으로 낮춤.
- 음악과 신음은 기존 파일을 사용하며 동일한 시작 시각을 유지. 음원 추가 없음.
- 실린더 사진 편집창의 display:none!important 충돌 수정. 숨김 상태에서는 계속 숨김.
- 업로드 사진이 화면 회전 시 기본 이미지로 덮이는 문제 수정. 재진입 시 저장한 사진을 읽은 후 시작.
- 기본 그림 복원 시 기본 레이아웃을 즉시 적용. 배경판을 교체한 뒤 편집 대상을 바꿔도 업로드 배경 유지.
- 기존 일시정지 상태를 유지하고, 진행 중 열었던 편집창을 닫으면 재개.
- 경기·적 스킬·라켓 터치·보상·스탯·게임 규칙 코드는 수정하지 않음.

## 실행 검증
Headless Chromium에서 실제 게임 문서를 iframe으로 실행함.
- 스쿼트 1/4/8단계: 90/120/150 BPM 각각 music=*_bgm, bed=*_bed, AudioContext=running 확인. 두 음원의 디코딩·재생 노드 활성화 확인.
- 실린더: 세로 편집창 표시, 중앙 이미지 업로드, 가로 회전, 편집창 닫은 뒤 재개, 게임 재진입 후 저장 사진 유지 확인.
- 배경판 업로드 후 대상 변경, 중앙 이미지·배경판 기본 복원 확인.
- 세로→가로→세로 크기 변경, 기존 일시정지 상태에서 편집창 개폐 확인.
- 위 실행 중 JavaScript pageerror 없음.

## 미확인
실제 Android 기기·실제 스피커로 청취하지 않음. 음량 변경값과 재생 상태를 확인했으며 사람이 귀로 들은 결과는 아님.
다른 6종 미니게임 전수 실행·완주, 보상·저장 회귀 테스트는 이번 범위에서 수행하지 않음.

## 적용
게임을 실행하는 기존 폴더의 동명 HTML을 이 ZIP의 HTML로 교체. 기존 assets 폴더 유지. 별도 음원이나 이미지 추가 불필요.
