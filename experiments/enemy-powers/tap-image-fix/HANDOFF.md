# 백만대 이미지·타격 좌표 교체

## 기준
GAIA-Dialogue-Portrait-Feather-Patch.zip의 GAIA-Pingpong-v12.11.html.

## 변경 파일
- GAIA-Pingpong-v12.11.html: DirectMinigames 문서 확장 뒤 tap 전용 패치.
- assets/minigames/miju-tap-1.png: 사용자 1000099273.png 그대로 복사(681×473).
- assets/minigames/miju-tap-2.png: 사용자 1000099274.png 그대로 복사(871×306).
- assets/minigames/miju-tap-3.png: 사용자 1000099271.png 그대로 복사(391×495).

## 범위
- 백만대의 세 자세와 시작 미리보기가 새 에셋을 사용하도록 경로 교체.
- PNG 원본 바이트와 기존 투명도 보존. 재생성·색 변경·크롭 없음.
- 이미지 전체를 받던 버튼을 표시 이미지의 실제 크기에 맞춰 산출하는 별도 판정 영역으로 변경.
- 이미지 내부 기준점: 1번 (0.61,0.55), 2번 (0.68,0.65), 3번 (0.50,0.60).
- 타격 효과 중심도 해당 버튼 중심을 사용. 게이지 위치 역시 새 이미지 비율 기준으로 갱신.
- 판정 영역은 이미지 표시 폭·높이의 28%, 최소 44 CSS px. 영역 밖 터치는 횟수에 포함하지 않음.
- ResizeObserver와 이미지 load 시 표시 크기·좌표 재계산.
- 게이지 증가·감소 수식, 애니메이션 키프레임, 사운드 호출, 보상·스탯·결과 공식 변경 없음.
- 다른 미니게임·시나리오·경기 코드 변경 없음. 기존 스쿼트 음량·실린더 MP4·대화창 페더 패치는 포함됨.

## 검증
Chromium 실행: 480×820(1단계), 960×540(10단계).
세 PNG의 실제 크기·로드 경로, 버튼 중심과 이미지 기준점 일치(1px 미만 오차), 최소 터치 크기 확인.
각 버튼을 터치 입력으로 1회씩 눌러 총 3회 반영, 영역 밖 입력은 추가 반영되지 않음을 확인.
가로·세로 스크린샷에서 이미지 전체 표시 확인. 세로 화면은 효과 종료 후 추가 시각 확인.
실행 중 pageerror 없음. verification/results.json 포함.

## 미확인
실제 Android 기기 조작, 전 단계 완주·성공·실패 보상 전수 회귀 검증 미수행.
검증 환경의 한글 폰트 글리프 표시 제한은 직전 작업과 같으며 폰트 변경 없음.
