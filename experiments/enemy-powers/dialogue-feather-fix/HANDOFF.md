# 대화 초상화 정리 및 시나리오 확인

## 변경
기준: 직전 GAIA-Cylinder-MP4-10sec-Patch.zip의 HTML.
- 대화 초상화 하단에 78%~100% 알파 페더 마스크 적용.
- 대화창 실제 높이를 ResizeObserver로 읽어 초상화 끝을 대화창 위쪽 경계보다 48~96px 아래로 배치.
- 대화창을 초상화보다 앞에 표시. 화면 회전·대사 길이 변경·폰트 로딩 시 위치 갱신.
- 인물 원본 에셋, 대사, 시나리오 조건, 세이브, 게임 로직 변경 없음.
- 백만대 이미지·타격 지점 교체는 미수행. 이번 ZIP은 대화 초상화 정리만 추가한 패치임.

## 시나리오 현황
STORY_SCENES에 28개 장면, 107개 대사 항목 확인.
월드투어 진입에는 프롤로그, 이후 특정 노드·선수·대회 조건에 따른 장면이 연결됨.
playScenes는 저장된 flags를 확인해 이미 본 장면을 생략하며, 일반 반복 경기·훈련마다 대사가 나오는 구조가 아님.
아케이드는 월드투어 시나리오 진행 경로와 별도임.
이번 작업에서는 장면 호출 조건을 임의 변경하거나 새 대사를 쓰지 않음.
사용자의 현재 세이브가 없어 실제 누락 장면·현재 flags 상태는 미확인. 새 테스트 세이브에서 확인한 장면 수가 사용자의 진행 상태를 뜻하지 않음.

## 검증
최종 HTML을 Chromium에서 실행하고 중립적인 QA 대사를 넣어 확인함.
480×820, 960×540, 1440×900에서 마스크·대화창 앞뒤 순서·하단 겹침·대화창 화면 내 배치 검증.
480×820, 960×540 스크린샷으로 초상화 하단 가림을 직접 확인.
검증 환경의 한글 폰트 표시가 정상적이지 않아 한글 글리프 품질은 확인하지 못함. 폰트 코드는 변경하지 않음.
pageerror 없음. 결과 JSON 포함.
모든 시나리오 완주와 실제 Android 테스트, 전체 미니게임 회귀 테스트는 미수행.
