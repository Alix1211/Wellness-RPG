# GAIA 스킬 연출 재수정 — 인수인계

2026-10-24 (한국 시간).

## 이번 지시와 변경

작은 알림처럼 지나가는 이전 연출은 사용자 의도와 달랐습니다. 이번 기준은 다음 순서입니다.

**경기 정지 → 큰 상대 초상화와 제공된 스킬 말풍선 → 확대·페이드 → 경기 재개와 동시에 패널티 시작.**

- 연출은 약 1.8초입니다. 등장 후 읽을 시간을 두고 마지막에 확대되며 사라집니다.
- 이 시간 동안 공 물리·라켓·카메라·경기 입력이 멈춥니다. 기술 효과의 지속시간과 폭탄 카운트는 아직 시작하지 않습니다.
- 연출 종료 때 효과를 적용하고 다음 프레임부터 경기를 재개합니다.
- 저성능 기기에서도 연출 시간이 과도하게 길어지지 않도록 연출 시계는 물리 계산의 0.05초 제한과 분리합니다.
- 가로는 초상화/말풍선을 나란히, 세로는 초상화 위·말풍선 아래로 크게 배치합니다.
- 사용자 제공 `1000100241.png`의 15개 말풍선을 원본 그대로 사용합니다. 3열×5행에서 각 기술에 맞는 영역을 표시하며 새 이미지를 생성하거나 문구를 다시 그리지 않았습니다. 원본 배경 가장자리는 표시 단계에서 부드럽게 처리합니다.
- 미끄러짐 스킬의 화면 빗금은 제거했습니다. 실제 이동 관성은 그대로 작동합니다.

## 유지

- 이전 적 공격 패턴과 26명 고정 기술 배정, 일반 5점/대회 7점/최종 결승 11점.
- 보통 기술 1회, 최종 결승 최대 3회.
- 기존 수비 예측/추적 함수 영역은 기준과 동일합니다.
- 기존 캐릭터·미니게임·지도 수선·탁구대 광택·카메라 보정·골드/경험치·저장 규칙 유지.
- 한국어 기술명 음성은 기기의 한국어 음성합성 지원이 있을 때만 재생하는 기존 구현입니다. 녹음 음원을 새로 만든 것은 아니며 Android 음성 청취는 확인하지 않았습니다.

## 실제 확인

PC Chromium 실제 경기 진입 후 서브와 AI 리턴을 진행해 자동 발동을 확인했습니다. 해당 확인에서는 스킬 활성화 함수를 직접 호출하지 않았습니다.

- 컷인 중 공 좌표, 카메라 좌표, 입력 목표 좌표가 그대로인 것을 비교했습니다.
- 컷인 중 패널티 active=null / pending=slippery이고 지속시간은 차감되지 않았습니다.
- 종료 후 slippery 활성화와 약 2초의 남은 지속시간을 확인했습니다.
- 재개 후 공이 다시 움직임을 확인했습니다.
- 제공된 15개 말풍선 영역이 서로 다르게 연결되고, 연출 완료 후 각 효과가 적용되는지 확인했습니다. 이 부분은 검사에서 강제로 연출을 시작한 경로입니다.
- 폭탄은 연출 종료 후 10초로 시작하고, 미주만 라켓 축소/상대만 확대가 유지됩니다.
- 가로 956×493와 세로 495×909에서 실제 화면을 확인했습니다. 이전 0.55초 작은 컷인과 다른 큰 연출입니다.
- 필요한 이미지 파일 404 및 JS pageerror는 없었습니다.
- 마지막 입력 처리 보정은 멈춤 중 끝난 터치는 해제하고, 계속 누르고 있던 터치 상태는 유지하는 변경입니다. 최종 빌드 구문 검사를 통과했습니다.

미확인: Android 실제 기기, 실기 프레임률·음성 청취, 15종 전부의 사람 조작 체감/밸런스. 코드·강제 발동 검사를 사람의 플레이 완료라고 보고하지 마세요.

## 소스와 다음 작업자

- `source/enemy-powers.js`: 큰 연출·정지·지연 효과 적용.
- `source/build-enemy-powers.cjs`: 기존 광택/카메라 보정 기준 HTML에 공격·패널티 및 이번 연출을 주입. CLI의 첫 인자는 기준 HTML, 두 번째는 출력 HTML입니다.
- `source/verify-cutin.cjs`: 실제 자동 발동/정지/재개 및 두 화면 배치 확인용. 경로와 Chromium 위치는 작업 환경 기준입니다.
- `validation.json`: 이번 확인 수치.
- `build-verification.json`: 기준 파일 SHA와 수비 AI 동일성/구문 검사.

기준은 이전 Enemy Powers v1 빌더와 같은 `GAIA-v12.11-table-gloss-camera-patch.zip`의 HTML입니다. 이미 Enemy Powers가 들어간 파일을 다시 빌더 입력으로 사용하지 마세요.
