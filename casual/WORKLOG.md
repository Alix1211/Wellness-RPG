- 프레임/음원 정리, 일시정지 중 음원 정지, 소리 설정 연동, 백업/복원 검증 추가.
- Android 별도 패키지, 네이티브 메뉴/백그라운드 진입 시 캐주얼 일시정지 연동. 실제 기기 검증은 이 환경에서 수행하지 못함.

## CASUAL-02 · 전체 복원과 진동
- 사용자 지시: 모든 게임 복원, 특히 스쿼트. 11종 전체 연결, 스쿼트 맨 앞 배치.
- CASUAL-01 저장의 새 게임 누락을 정상 이전으로 처리. 기존 스탯과 단계 기록 유지.
- SquatGame 기존 의상 스프라이트/음원/90·120·150 박자 유지, roomId 결과 연결, 소리 설정과 pause/quit 처리.
- Java 직접 진동 브리지, VIBRATE 권한, 켜기/끄기/테스트, 이벤트 연동, 백그라운드 취소.
- Android 컴파일/서명 성공. 브라우저 93항목/110단계 문법 통과. 스쿼트 자동 원격 입력 첫 시도는 420점 실패, 문서 내부 DOM 입력으로 2800점 성공. 실제 모터 확인은 미완료.
- 최종 빌드 중 중간 산출물 충돌로 서명 단계 Missing AndroidManifest 오류가 한 번 발생. 생성 출력만 정리하고 빌드 잠금을 추가하여 동시 실행을 방지한 뒤 순차 재빌드.

## CASUAL-03 · 전체 음원 검사
- 실제 파일 분석: hit_slap 첫 유효 신호 약 0.594초, hit_punch 약 0.730초. 부모 숨김 감시가 260ms마다 재생을 끊어 레거시 반응 누락.
- 스쿼트 good/perfect 판정의 찰싹/일반 반응 누락과 배팅 lightHit의 반응 누락 확인. 기존 음원으로 연결.
- 6종 레거시 자체 믹서, 앞 무음 제거, 스쿼트 BGM 레벨 조정, pop/boing/whoosh 전달, 결과 전용 부모 믹서와 음향 테스트 추가.
- 초기 자동 검사에서 suspended AudioContext 분석기의 마지막 버퍼를 소리 재생으로 오인한 일시정지 false positive 수정.
- 움찔 자동 클릭은 흔들림 안정 대기 중 다른 대상이 되어 오답을 누르는 문제가 있어 문서 내 DOM 클릭으로 입력. 배팅은 Window 대상 합성 키 이벤트에 matches 메서드가 없어 테스트가 실패했고 canvas 대상으로 바꾸어 실제 판정 입력을 검사. 게임 점수/결과 주입 안 함.
- 실제 기기 스피커/음량은 이 환경에서 확인하지 못함.
