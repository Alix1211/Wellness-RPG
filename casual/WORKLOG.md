# CASUAL-01 작업 기록

- 기준 main: b3d31995107172355cf030328b9ac4f2289aa747. 기존 main 보존, codex/gaia-casual-01 분기.
- 사용자 승인: 퀘스트/생활 압박을 제거하고 스탯 성장 중심의 가벼운 미니게임 모음으로 전환.
- 기존 R61 로컬 수정본과 사용자 제공 에셋/게임 문서 생성기를 재사용. 새 셸/저장/보상/단계 흐름 추가.
- 초기 브라우저 설치: 기본 Playwright 다운로드가 잘못된 ZIP으로 실패. npm Chromium 묶음은 추출 중 chown 환경 오류로 실패하여 Brotli를 직접 풀어 사용.
- 첫 생성에서 기존 문서 문자열 내부의 body 닫기까지 치환하는 오류 발견. 마지막 실제 body만 대상으로 수정.
- 원본 줄 자르기 렌더러의 root 미정의 참조를 새 버전에서 window로 정리.
- 새 부모 화면에 기존 내장 한글 폰트를 등록해 글자 네모 표시 수정.
- 물병의 보이지 않는 입구/빈 그림 판을 병 모양과 눈에 보이는 입구로 교체. 손가락 위치를 직접 조준하도록 입력 변경.
- SceneEditor가 초기화하며 덮는 입구/목표 폭을 단계별 layout으로 지정. 자식 편집 메뉴 제거해 잘못된 편집 진입 방지.
- 결과 후 제거한 iframe을 찾는 기존 메시지 핸들러 오류 발견. 캐주얼 모드에서 즉시 반환하고 null 안전하게 처리.
- 프레임/음원 정리, 일시정지 중 음원 정지, 소리 설정 연동, 백업/복원 검증 추가.
- Android 별도 패키지, 네이티브 메뉴/백그라운드 진입 시 캐주얼 일시정지 연동. 실제 기기 검증은 이 환경에서 수행하지 못함.
