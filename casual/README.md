# GAIA CITY CASUAL-01 — 캐주얼 전환 테스트판

기존 R60 RPG를 덮어쓰지 않는 별도 버전입니다. 장소 선택 → 게임/단계 선택 → 한 판 → 짧은 결과 → 다음 단계/재도전으로 진행합니다.

- 물병, 줄 자르기, 균형, 물어와, 배팅, 실린더: 각각 독립적인 10단계.
- 각 게임의 1단계는 처음부터 열림. 이전 단계 성공 한 번으로 다음 단계 해금.
- 퀘스트·강제 이동 미션·생활비·스탯 감소·입장 체력 비용·실패 후 강제 후속 게임은 실행하지 않음.
- 한 판 완료: 주 스탯 +1, 성공 +2, 해당 단계 첫 성공 +3. 보조 스탯은 주 스탯 보상의 1/4. 중단은 보상/손실 없음.
- 색기/음란도/복종도/개방성은 기존 명칭 유지. 여러 게임을 통해 각 스탯 성장 가능.
- 스탯 합계로 기존 사복/요가복/오피스 옷장 해금. 성공 단계 수로 기존 배경 해금.
- 기존 제공된 캐릭터, 배경, 게임 동작, 효과 스티커와 음원 재사용. 물병은 입구가 보이는 캔버스 병으로 표시.
- 물어와는 자동 전진. 연타 가속/점프/충돌 감속이 있는 독립 게임.
- 실린더는 안정 구간 유지 모델. 1→10단계에서 폭 50.4→18로 감소. 실패는 결과로 종료.

## 설치/저장

`GAIA-CASUAL-01.apk`: 패키지 `com.gaia.casual`, 앱 이름 GAIA CASUAL. 기존 `com.gaia.life`와 함께 설치 가능. 기존 RPG 데이터에 접근하지 않음. Android 8 이상, 화면 회전 허용. 같은 기존 서명 키 사용.

`GAIA-CASUAL-01.html`: 에셋을 포함한 오프라인 단일 파일. 브라우저에서 열어 테스트 가능. 브라우저/앱의 저장은 서로 별개.

캐주얼 기록 키: `gaia-casual-save-v1`. 집의 기록 백업/불러오기는 캐주얼 JSON 전용. 기존 RPG 세이브를 이 형식으로 자동 변환하지 않음. 기존 복도 꾸미기/퀘스트 등의 코드와 기존 기록은 기존판에 보존되며 새 캐주얼 메뉴에서 실행하지 않음.

## 재현

원본 main R60 복원 후 R61 수정 스크립트를 적용한 정확한 SHA256 입력을 사용합니다. 원본 HTML 파일을 별도로 보존한 상태에서 아래를 실행합니다.

```sh
python tools/gaia/restore.py
python tools/gaia/r61-flee-input.py
python casual/build.py
python casual/build-apk.py
```

`build.py`는 입력 해시를 검사하고 `GAIA-CASUAL-01.html`을 별도 생성합니다. R61 입력이 이미 있으면 앞의 두 단계를 생략합니다. `build-apk.py`는 유지 중인 Android 래퍼를 복사해 패키지/앱 이름/방향/일시정지 연동만 바꾸며, 키는 기존 android/private에서 읽고 복사하지 않습니다. Android SDK 35/Java 17 필요.

원본 RPG의 load/frame 루프와 save를 새 버전에서 실행하지 않습니다. 원본 게임 문서 생성기를 재사용하고, 새 호스트가 게임창의 생명주기와 보상을 소유합니다. 결과·중단 시 프레임과 음원 정리, 이전 프레임 메시지 무시, 중복 보상 방지.

## 검증 범위와 남은 사항

`verification.json`: 실제 포인터로 줄 자르기와 물병 1단계 성공, 저장/단계 해금, 여섯 게임의 일시정지·중단·취소·실패·재도전, 중복 메시지, 기존 저장 보존 검사. 실패 처리는 테스트 안에서 원본 모델 타임아웃/종료 함수를 호출해 결정적으로 검사하며, 자연 플레이로 모든 실패를 관찰했다는 뜻이 아닙니다.

`apk-verification.json`: APK 서명, ZIP 정렬/CRC, 내장 HTML 해시 검사. `manifest.json`은 실제 HTML 식별값.

60개 조합의 문서 생성/스크립트 문법 검사와 전 단계 플레이 검증은 다릅니다. **60단계 전체 난이도 조정, 실제 Android 설치/터치/스피커 음향 검증은 미완료**입니다. 새로 추가하지 않은 기존 게임(움찔/합치기/백만대/뒤를 조심/스쿼트)은 원본 소스에 보존했고, 이 첫 전환판의 선택 목록에는 노출하지 않았습니다.
