## 2. 이번 작업의 목표

**당하는 지점 미니게임 [확정]**: 정해진 지점에서 **전투 결과와 무관하게 무조건** 미니게임이 나옵니다. 케인 표현: "이게 그녀를 위한 복지 정책이다." 방향은 느와르가 아니라 **에로 코믹**, 패배는 어두운 게임오버가 아니라 **코믹한 곤욕**.

미니게임은 두 종류로 씁니다.

| 종류 | 언제 | 비고 |
|---|---|---|
| A. 당하는 미니게임 | 매 바퀴 필수, 단계 끝에 자동 시작 | 결과에 상관없이 다음 단계로 진행 |
| B. 센터/착유농장 스탯 미니게임 | 플레이어가 입장 화면에서 고름, 바퀴당 횟수 제한 | 골드(센터비)를 내고 스탯 상승(느리게). **스탯 체계 미정 [임시]** |

## 4. 게임 연결 방식 (제안, 아직 코드에 없음) — 이 계약대로 만들어 주세요

### 4-1. 새 모듈 `js/minigame.js` (index.html에서 `shop.js` 뒤, `ui.js` 앞)
```js
G.minigame = {
  register(id, def),        // def = { name, start(ctx) }  각 미니게임이 자기 자신을 등록
  play(id, opts, onDone),   // 전체 화면을 열고 시작. 끝나면 onDone(result)
};
// ctx (start에 전달)
{ root,        // 전체 화면 컨테이너(#minigame, position:absolute; inset:0; z-index 48) — index.html에 추가
  bg,          // 배경 이미지 URL (place/<장소>_port.webp 또는 기본)
  mode,        // 'splat'(A. 당하는) | 'train'(B. 스탯)
  wl,          // 월드 레벨(난이도 가감용)
  finish(r) }  // 끝났음을 알림. r = { score(0~100), tier:'fail'|'ok'|'great', reward:{ gold, stat? } }
```
- 결과 `tier`와 상관없이 **A는 항상 다음 단계로 진행**합니다. `fail`이어도 게임오버 없음(코믹 대사만 다름).
- 보상 수치는 한 곳 `const MINI = {...}`에서만 조정(전투 `SLOT` 상수처럼). **[임시]** A: 골드(알바비) 소량. B: 센터비 차감 후 스탯 소량.
- 끝나면 반드시 `G.run.save()`, 화면을 닫고, 지도(`G.map.open()`) 또는 호출한 입장 화면으로 복귀.

### 4-2. A(당하는) 연결 지점
- `data/flow.js`의 단계 객체에 `mini: 'squat'` 같은 필드를 추가(없으면 없음).
- `js/run.js`의 `afterFight()` 안, `stepDone()` 호출 **직전**에: 현재 단계에 `mini`가 있으면 `G.minigame.play(c.mini, {mode:'splat'}, r => { 보상 적용; save(); stepDone(); })`.
- 휴식(경찰서) 단계에는 넣지 않습니다. **한 바퀴에 적어도 한 번은 반드시 발생**해야 하므로, 모든 바퀴 표(`steps`, `steps2`)에 `mini` 단계가 최소 1개 있는지 확인하세요.
- 현재 1막 표는 `data/flow.js` `steps`(9단계), 2막 표는 `steps2`(9단계). 2바퀴 이후는 `steps2`를 반복합니다.

### 4-3. B(센터/착유농장) 연결 지점
- `js/shop.js`의 `KINDS`와 `drawEntry`가 입장 화면입니다. 착유농장(`farm`, 인물 오 예비역)에 **"훈련" 버튼**을 추가하고, 항상 열려 있게 하세요(케인: "그래야 스탯 노가다를 할 수 있다").
- 횟수 제한은 슬롯의 방식과 같게: `run.slot = {lap, n}`처럼 `run.mini = {lap, n}`을 두고 **바퀴당 N회 [임시]**. 다 쓰면 버튼을 회색으로.
- **스탯 종류·상승량은 케인이 정하기 전이므로 임의 확정 금지.** 구현은 "스탯 이름 → 값" 맵(`run.stat = {}`)과 상수 `MINI.stat`만 만들어 두고, 실제 전투 효과 연결은 하지 마세요. 케인이 정하면 Claude가 연결합니다.

## 5. 각 미니게임 공통 요구

- 세로 화면에서 **한 손 엄지 조작**(탭·길게 누르기·좌우 드래그) 위주. 길이 **20~40초** [임시].
- 주인공은 보라 요가복 SD/일러스트 재사용. 연출은 **코믹**, 직접적인 묘사 지문 없이 **대사창과 이펙트(하트·의성어)** 로 표현. 의성어는 기존 `HITS = ['퍽!','짜악!','철썩!','탁!','뿅!']` 톤을 따르세요.
- 시작 화면 없이 바로 시작하거나, 한 줄 안내 + 시작 버튼 하나만. 결과 화면은 대사 한 줄 + "확인" 버튼 하나.
- 난이도는 월드 레벨(`ctx.wl`)로 약간만 가감.
- 모든 버튼 `touch-action:manipulation`, 더블탭 확대 방지, 화면 회전 시 깨지지 않기.
- 저작권이 불분명한 음원·그림 추가 금지.

### 11-2. 게임 구조 (기존 스쿼트, 이미 분석 완료)
- 단일 HTML 안에 게임 문서(`DOC`)가 문자열로 들어 있고, 설정(`CFG`)으로 이미지를 주입합니다. 주입 항목: `background`, `squat.front/back`(시트), `squat.fb/bb`(**앉았을 때 타점이 되는 프레임 번호**, 0부터), `squat.ball`(기구 이미지), `squat.floor`, `squat.fx`.
- 시트 규격: 칸 `FW=275, FH=456`, `FRAMES=12`, `COLS=6`. 캐릭터는 칸 안에서 **발 바닥이 y≈451**, 가로 가운데 정렬. 프레임 0=서 있는 자세, **프레임 6=가장 깊이 앉은 자세(앞·뒤 모두 fb=bb=6)**, 11=거의 일어난 자세.
- 박자: 한 박자 동안 12프레임이 흘러가고, 타점 시각이 프레임 `fb`의 한가운데가 되도록 맞춰져 있습니다. **프레임을 바꾸면 반드시 fb/bb(앉은 프레임 번호)를 다시 확인**하세요.
- 난이도 3종(쉬움 90 / 보통 120 / 어려움 150 BPM)과 결과 메시지(`wellness-result`, `wellness-close`, `game-retry` postMessage)는 기존 그대로. GAIA 쪽 연결은 §4의 `G.minigame` 계약으로 감싸세요(결과 `score` = `ratio*100`, 실패여도 진행).
- 사운드는 `window.GAIA_SOUND_SOURCES`(base64)로 주입됩니다. 시험판에 전부 들어 있으니 그대로 쓰세요.

### 11-3. 시험판에서 바꾼 것 (이식 시 그대로 가져갈 것)
1. **배경**: 화면이 가로(`W > H*1.15`)면 `backgroundL`, 아니면 `background`를 씁니다(`renderBack`). 배경에 바닥이 있으므로 `squat.noFloor:true`로 **별도 바닥 그림 생략**.
2. **받침대**: `squat.stand`. 캐릭터 그림자 위·기구 아래에 그립니다. 바닥선(`floorY+4s`)에서 위로 `sh`만큼.
3. **기구(ball)**: 크기 `ds`로 축소, 받침대 윗면 위에 얹음(`dy`로 미세 보정).
4. **판정 링·파문**: 크기는 **원래 기구 크기로 고정**(`rs` 배율만), 중심은 **새 기구 중심 + `ry`** 를 따라감. 박자 판정(`perfect/good` 시간 창)은 변경 없음.
5. **캐릭터**: 크기 `cs`, 높이 `cy`(발 바닥 기준).
6. 위 값들은 모두 한 객체 `DEV`(시험판에서는 `window.DEV`, 슬라이더로 편집, 브라우저에 저장)에서 읽습니다: `ds, dy, sh, ss(받침대 폭 배율), rs, ry, cs, cy`. **현재 기본값**: `ds .5, dy 0, sh 72, ss 1.5, rs 1, ry 0, cs 1, cy 0`. 단위는 `s`(화면 배율)를 곱하는 게임 내부 단위.
7. 이식할 때 `DEV`는 **고정 상수 한 곳**(`const SQUAT_LAYOUT = {...}`)으로 바꾸세요. 케인이 시험판에서 "값 복사"로 보내 주는 JSON 값을 그대로 넣으면 됩니다. **그 값은 아직 안 왔습니다(미정).** 값이 오기 전에는 위 기본값으로 두세요.

### 11-4. GAIA 연결 방식 [임시 제안 — 케인 확정 전]
- 케인 말: "**집에 가면 체력(?)단련 미니게임**". 즉 **주인공의 집**에서 하는 B형(스탯 훈련) 미니게임입니다. 물음표가 붙어 있듯 **스탯 이름이 "체력"으로 확정된 것은 아닙니다.** 스탯 체계는 아직 없으니 §4-3의 `run.stat` 맵과 상수만 만들고 이름은 `'체력'`(임시)으로 두세요.
- **집 입장 지점**(지도 어디, 입장 화면에 어떤 버튼)은 **미정**입니다. 케인이 정해 줄 때까지 §4-3의 입장 화면 방식(`js/shop.js` KINDS)으로 `home` 항목만 추가해 두고, 바퀴당 횟수 제한과 회색 버튼 규칙(§0-3)은 그대로 적용하세요.
- 배경은 이 게임 안에서만 집 배경을 쓰고, 전투 배경 풀(`place/*`)과는 섞지 마세요.
- 비키니 차림은 현재 영상 소스 그대로의 임시 의상입니다. 케인이 의상을 바꿔 오면 **시트만 교체**하면 됩니다(칸 규격·fb 확인 필수).
