## 2. 이번 작업의 목표

**당하는 지점 미니게임 [확정]**: 정해진 지점에서 **전투 결과와 무관하게 무조건** 미니게임이 나옵니다. 케인 표현: "이게 그녀를 위한 복지 정책이다." 방향은 느와르가 아니라 **에로 코믹**, 패배는 어두운 게임오버가 아니라 **코믹한 곤욕**.

미니게임은 두 종류로 씁니다.

| 종류 | 언제 | 비고 |
|---|---|---|
| A. 당하는 미니게임 | 매 바퀴 필수, 단계 끝에 자동 시작 | 결과에 상관없이 다음 단계로 진행 |

## 4. 게임 연결 방식 (제안, 아직 코드에 없음) — 이 계약대로 만들어 주세요

### 4-1. 새 모듈 `js/minigame.js` (index.html에서 `shop.js` 뒤, `ui.js` 앞)
```js
G.minigame = {
  register(id, def),        // def = { name, start(ctx) }  각 미니게임이 자기 자신을 등록
  play(id, opts, onDone),   // 전체 화면을 열고 시작. 끝나면 onDone(result)
};
// ctx (start에 전달)
{ root,        // 전체 화면 컨테이너(#minigame, position:absolute; inset:0; z-index 48) — index.html에 추가
  bg,          // 배경 이미지 URL (place/<장소>_port.webp 또는 기본)
  mode,        // 'splat'(A. 당하는) | 'train'(B. 스탯)
  wl,          // 월드 레벨(난이도 가감용)
  finish(r) }  // 끝났음을 알림. r = { score(0~100), tier:'fail'|'ok'|'great', reward:{ gold, stat? } }
```
- 결과 `tier`와 상관없이 **A는 항상 다음 단계로 진행**합니다. `fail`이어도 게임오버 없음(코믹 대사만 다름).
- 보상 수치는 한 곳 `const MINI = {...}`에서만 조정(전투 `SLOT` 상수처럼). **[임시]** A: 골드(알바비) 소량. B: 센터비 차감 후 스탯 소량.
- 끝나면 반드시 `G.run.save()`, 화면을 닫고, 지도(`G.map.open()`) 또는 호출한 입장 화면으로 복귀.

### 4-2. A(당하는) 연결 지점
- `data/flow.js`의 단계 객체에 `mini: 'squat'` 같은 필드를 추가(없으면 없음).
- `js/run.js`의 `afterFight()` 안, `stepDone()` 호출 **직전**에: 현재 단계에 `mini`가 있으면 `G.minigame.play(c.mini, {mode:'splat'}, r => { 보상 적용; save(); stepDone(); })`.
- 휴식(경찰서) 단계에는 넣지 않습니다. **한 바퀴에 적어도 한 번은 반드시 발생**해야 하므로, 모든 바퀴 표(`steps`, `steps2`)에 `mini` 단계가 최소 1개 있는지 확인하세요.
- 현재 1막 표는 `data/flow.js` `steps`(9단계), 2막 표는 `steps2`(9단계). 2바퀴 이후는 `steps2`를 반복합니다.

### 4-3. B(센터/착유농장) 연결 지점
- `js/shop.js`의 `KINDS`와 `drawEntry`가 입장 화면입니다. 착유농장(`farm`, 인물 오 예비역)에 **"훈련" 버튼**을 추가하고, 항상 열려 있게 하세요(케인: "그래야 스탯 노가다를 할 수 있다").
- 횟수 제한은 슬롯의 방식과 같게: `run.slot = {lap, n}`처럼 `run.mini = {lap, n}`을 두고 **바퀴당 N회 [임시]**. 다 쓰면 버튼을 회색으로.
- **스탯 종류·상승량은 케인이 정하기 전이므로 임의 확정 금지.** 구현은 "스탯 이름 → 값" 맵(`run.stat = {}`)과 상수 `MINI.stat`만 만들어 두고, 실제 전투 효과 연결은 하지 마세요. 케인이 정하면 Claude가 연결합니다.

## 5. 각 미니게임 공통 요구

- 세로 화면에서 **한 손 엄지 조작**(탭·길게 누르기·좌우 드래그) 위주. 길이 **20~40초** [임시].
- 주인공은 보라 요가복 SD/일러스트 재사용. 연출은 **코믹**, 직접적인 묘사 지문 없이 **대사창과 이펙트(하트·의성어)** 로 표현. 의성어는 기존 `HITS = ['퍽!','짜악!','철썩!','탁!','뿅!']` 톤을 따르세요.
- 시작 화면 없이 바로 시작하거나, 한 줄 안내 + 시작 버튼 하나만. 결과 화면은 대사 한 줄 + "확인" 버튼 하나.
- 난이도는 월드 레벨(`ctx.wl`)로 약간만 가감.
- 모든 버튼 `touch-action:manipulation`, 더블탭 확대 방지, 화면 회전 시 깨지지 않기.
- 저작권이 불분명한 음원·그림 추가 금지.
