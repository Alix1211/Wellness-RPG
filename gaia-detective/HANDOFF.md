## 2. 확정된 전투 규칙 (config.js 기준)
- HP 80, 에너지 3, 드로우 5.
- **도파민 0~100:** 피격 피해의 100%가 쌓임. 가득 차면 다음 턴 시작에 **절정** 발동: 에너지 +2, 공격/체포 피해 ×2. 턴 종료 시 도파민 초기화, 다음 턴은 쿨다운.
- **조임력 0~40:** 피격 1회당 +1. 적에게 피해의 절반 반사, 적 힘 −1.
- **윤활도 0~100:** ≥30 드로우 +1, ≥70 첫 카드 비용 −1, 턴마다 −10.
- 적은 **기력**만 사용(HP 없음). **질림** = 해당 적의 이번 턴 공격 의도 취소(엘리트는 이후 2턴 면역, 보스는 첫 공격 행동만 취소). **봉쇄** = 도주 차단.
- 도주 확률: normal 0.2 / elite 0.15 / boss 0.1 (fleeRatio).
- 키워드 12종, 카드당 효과 최대 2개.
- 시작 덱 12장.
- **미확정:** 패배 조건, 성장 스탯 4종(색기·음란도·복종도·개방성 — 케인 확인 전), 카드 보상 등급 확률, 일반 전투 난이도(시뮬상 너무 쉬움).

## 5. 기술 구조
- 클래식 `<script>` 전역 `window.GAIA` (config, cards, enemies, engine, sfx, ui). fetch 안 씀.
- `js/engine.js`는 DOM을 모름. 상태 `S`, 이벤트 큐 `S.events` → `ui.js`가 `playEvents()`로 SFX/파티클/의성어 연출.
- UI: vh 기준 크기, 필드 영역 약 3.3~4.2:1, 손패 그리드. 효과: `burst`, `comic`, `flash`, `fieldShake`, `flyCard`. 카드 DOM에 `data-uid`.
- SFX: `js/sfx.js` WebAudio 합성음 + 얼굴 때리는 mp3. 음소거 버튼(localStorage `gaia_mute`).
- 개발 패널(⚙): 전투 선택, 도파민/조임력/윤활도 조작, 손패에 카드 추가. URL `?enc=e1..e6`.
- 단일 HTML 빌드: `cd gaia-detective && python3 tools/build_single.py <출력경로>` → 이미지/mp3를 base64로 인라인(`GAIA_IMG`, `GAIA_SND`).
- 시뮬레이션: `node tests/sim.js 300` (무작위 플레이). 최근: 일반전 ~100% 승, 보스 ~80%, 절정 보스전당 ~1회.
- 로컬 확인: 저장소 루트에서 `python3 -m http.server 8765`, Playwright(Python, Chromium)로 스크린샷. 적이 둥실거려 클릭 시 `click(force=True)` 필요.
- Git 주의: Stop hook이 "unpushed commits"를 오탐하면 `git fetch` 후 tracking ref(update-ref)를 맞추고 `git ls-remote`로 실제 푸시 확인.

## 7. 스테이지 구조 (2026-10-22 상의 결과, 초안 — 케인이 "니 맘대로 짜라"고 위임함)
케인이 말한 원안: 경찰서를 자주 오가며 → 클럽에 댄서로 잠입해 VIP를 낚으려다 → 뒷골목에서 당하고 → 경찰서에서 심기일전 → 다시 클럽(이번엔 성공) → 로비에서 발각 → 착유농장에 끌려가고 → 경찰서에서 심기일전 → 마침내 스위트룸에서 당하고 → 체포.

| 순서 | 장소 | 내용 | 의상(제안) |
|---|---|---|---|
| ① | 경찰서 | 시작, 회복·카드 정비 | 경찰복 |
| ② | 클럽 | 댄서 잠입, 일반전 2 | 보라 반짝이 |
| ③ | 뒷골목 | 쫓겨 와서 당함. 일반전 2 + 엘리트 1 | 청바지 가죽 |
| ④ | 경찰서 | 심기일전(회복+카드) | 경찰복 |
| ⑤ | 클럽 | 재잠입 성공, 일반전 2 + VIP 접촉 | 마스크 |
| ⑥ | 로비 | 발각, 엘리트전 → 착유농장행 | 레이스 드레스 |
| ⑦ | 착유농장 | 탈출전, 일반전 2 | 젖소 |
| ⑧ | 경찰서 | 마지막 심기일전 | 경찰복 |
| ⑨ | 스위트룸 | 보스전 → 당하지만 체포로 역전 | 빨간 드레스 |

- 경찰서 = 고정 거점(휴식). 장소 폴더(`folder`)별 카드가 그 장소 보상에서 더 잘 나오게 하는 안.

### 7-0. 세계관 설정: 보라 요가복 = 포로복 (케인 설정, 2026-10-22)
- 보라색 요가복은 범죄자들이 입힌 **포로 복장**이다.
- 그녀는 괴롭힘(?)당하는 걸 **좋아한다.** 더 해달라고 조르고, 범죄자들은 "제발 집에 가라"며 쫓아낸다.
- 즉 **탈출이 아니었다.** 새디스트인 남자 범죄자들도 **질려서** 내보낸 것. "역시 에이스는 다르다."

- **확인됨(케인):** 이 보라 요가복은 **이전 Wellness-RPG 미니게임에서 쓰던 의상 그대로**다(거의 전부 이 의상). `purple_sparkle`(보라 반짝이)과는 다른 의상. 따라서 미니게임은 기존 Wellness-RPG의 보라 요가복 에셋을 재사용(새 그림 불필요 예상). 에셋 위치는 Wellness-RPG 저장소 안에서 찾을 것(아직 확인 안 함).

- **엔딩 없음.** 케인: "끝은 질려서 그만하면 끝이지." 무한 반복 일상물.
- §7의 9단계 표는 **"한 바퀴"의 기본 형태**로 본다. 2바퀴째부터 같은 장소를 쓰되 적 조합·이벤트·미니게임·대사를 풀에서 섞어 뽑는다(만들 양을 늘리지 않고 재활용).
- 난이도: 미리 고정하지 않고 **월드 레벨**로 올리는 방향. 스탯 연동(위쳐3식)은 **센터 미니게임 스탯 노가다와 충돌**(올릴수록 적도 강해져 헛수고)하므로 **기각, 월드 레벨 방식 확정**(케인 2026-10-22: "그래야 노력한 만큼 강해진 느낌을 매번 느낄 수 있다, 그게 낫다").
  - B: 한 바퀴 돌면 월드 레벨 자동 +1 / C: 한 바퀴 끝에 올릴지 선택. **B/C 미정**(맵·보상 만들 때 정함).
  - 월드 레벨 상승 시 변화 후보: 적 기력·힘 증가, 보상 카드 등급 상승, 새 적 혼합. (후보일 뿐 미확정)
- 당하는 지점 미니게임은 매 바퀴 무조건 발생(§7-1)해서 게임오버 없이 순환 가능.

### 7-01. 컨셉 방향: GCPD 일상물, LA 패러디 환락가 (케인 제안, 2026-10-22)
- 케인 발언 요지: 클럽, 카지노, 물장사하는 환락가, 저질영화(가이아 시티에도 있음) 촬영소 등을 무대로, **약간 LA 패러디 느낌의 GCPD(가이아 시티 경찰) 일상물**로 간다.
- 위 장소들은 장소 풀을 넓히는 후보다. 현재 맵 건물 5곳(§7-2)에 없는 곳: 카지노, 물장사 가게, 영화 촬영소. 맵에 추가할지·어떻게 해금할지는 **미정**(상의 필요).
- 연결점(제안일 뿐): 카지노는 케인이 재밌게 한 "배팅" 미니게임과 맞닿음.
- 세부 에피소드·대사·인물은 케인이 요청하기 전에 임의로 창작하지 말 것.

### 7-02. 골드 경제 (케인 제안, 2026-10-22)
- 골드가 있다: **벌어서 센터에서 쓴다.** 센터 = 능력(스탯) 올리는 미니게임 번외 페이지(§7-1). **센터 이용료(센터비)**를 낸다.
- 수입원: **월급 외에 "알바비" = 악당들에게 받은 용돈.** 케인: "주인공도 도덕적으로 훌륭할 필요는 없잖아?" (코믹한 비리 형사 톤, LA 경찰물 패러디와 맞음)
- 이로써 센터 스탯 노가다는 골드가 속도 조절 장치가 된다(케인이 앞서 말한 "느리게 오르고"와 일치).
- **미정:** 골드 수입 세부(전투 승리/체포 시 용돈, 한 바퀴 끝 월급 등), 슬롯머신 등 미니게임에서 골드를 걸지 여부, 상점(마트)에서 골드 쓰는지, 덱 정리(카드 제거) 방식.

### 7-03. 슬롯머신 경품 = 잡템 (케인 제안, 2026-10-22)
- 슬롯머신 보상으로 **잡템**을 준다. 케인이 든 예: 최음제 물약, 자양강장제 음료, 수갑(경찰용 아님), 채찍, 안대, 딜도 등 "쓸데없는 잡템".
- 케인이 든 예시는 "그런 쪽이다" 수준의 경향이며 확정 목록이 아님.
- **방향 확정(케인 2026-10-22): 효과가 있는 소모품으로 간다** (전투 중 한 번 쓰면 도파민 상승·기력 회복 등). 슬레이 더 스파이어의 포션에 해당. 케인은 슬더스에 포션·유물이 있는 줄 몰랐음 → 포션/유물 개념부터 설명하고 매칭하는 중.
- 유물(영구 패시브)은 **미정**, 소모품 먼저.

### 7-04. 파밍 루프 (케인 구상, 2026-10-22) — 케인은 파밍을 좋아함
- 케인 발언 요지: "던전(스테이지) 돌고 → 삥 뜯고(아니 용돈 받고) → 아이템 수집 → 마트 가서 팔고 좋은 건 챙기고 → 카지노 가서 슬롯 돌리거나 → 환락가 가서 남자분을 산다. 이세계 미혼 여성의 표본." 케인은 슬레이 더 스파이어에 포션/유물이 있는 줄 몰랐고 파밍을 좋아함.
- 루프: 스테이지 전투(용돈·아이템 획득) → 마트(**잡템 판매**, 좋은 건 보관) → 카지노(슬롯, 경품) / 센터(스탯 미니게임, 센터비) / 환락가(골드 지출처).
- 함의: 골드 수입원에 "아이템 판매" 추가, 지출처에 마트·센터·환락가. 아이템 등급(일반/특별/희귀)을 두면 파밍 동기가 강해짐(카드 등급 체계 재사용 가능).
- **환락가(케인 2026-10-22):** 돈 내고 당하러 가는 곳. **지금은 얻는 효과 없음**(코믹 연출용 지출처, 나중에 필요하면 붙임). **카지노는 아이디어 수준**이며 구현 계획 아님.
- **미정:** 아이템 판매가와 드랍 확률, 마트 구매 목록.

### 7-1. "당하는 지점" = 미니게임 (확정: 무조건 발생)
- 뒷골목 / 로비→착유농장 / 스위트룸 등 정해진 지점에서 **전투 결과와 무관하게 미니게임이 무조건 나옴.** 케인 표현: "이게 그녀를 위한 복지 정책이다." **건너뛰기 넣지 말 것.**
- 방향: 느와르가 아니라 **에로 코믹**. 패배는 어두운 게임오버가 아니라 코믹한 곤욕 미니게임.
- 케인이 재밌게 한 미니게임(우선순위): 배팅, 스쿼트, 물어오기, 뒤로 당겼다 던져 맞추기, 움찔 찾기, 찰싹찰싹. (나머지는 안 하게 되더라 → 만들지 않음)
- 배치 제안(미확정): 뒷골목→움찔 찾기/찰싹찰싹, 로비→착유농장→스쿼트/리듬, 착유농장→물어오기, 스위트룸→배팅, 클럽→당겨 던지기.
- 미니게임은 **센터(번외 페이지)에서도 재활용**: 맵 버튼으로 진입하는 선택 콘텐츠, 안 해도 그만, 스탯 노가다용. 스탯은 느리게 오르고 상한을 둠. 가끔 낮은 확률로 카드 드랍(성취감). 흐름을 깨지 않도록 "센터에 가서 따로 받는다"는 설정.
- 케인 농담 메모(구현 요청 아님): "울며 겨자먹기" 이벤트(남자들을 컨베이어에 태우고 배팅).
- **미니게임은 작업 순서상 맨 마지막.**
