## 2. 확정된 전투 규칙 (config.js 기준)
- HP 80, 에너지 3, 드로우 5.
- **도파민 0~100:** 피격 피해의 100%가 쌓임. 가득 차면 다음 턴 시작에 **절정** 발동: 에너지 +2, 공격/체포 피해 ×2. 턴 종료 시 도파민 초기화, 다음 턴은 쿨다운.
- **조임력 0~40:** 피격 1회당 +1. 적에게 피해의 절반 반사, 적 힘 −1.
- **윤활도 0~100:** ≥30 드로우 +1, ≥70 첫 카드 비용 −1, 턴마다 −10.
- 적은 **기력**만 사용(HP 없음). **질림** = 해당 적의 이번 턴 공격 의도 취소(엘리트는 이후 2턴 면역, 보스는 첫 공격 행동만 취소). **봉쇄** = 도주 차단.
- 도주 확률: normal 0.2 / elite 0.15 / boss 0.1 (fleeRatio).
- 키워드 12종, 카드당 효과 최대 2개.
- 시작 덱 12장.
- **미확정:** 패배 조건, 성장 스탯 4종(색기·음란도·복종도·개방성 — 케인 확인 전), 카드 보상 등급 확률, 일반 전투 난이도(시뮬상 너무 쉬움).

## 5. 기술 구조
- 클래식 `<script>` 전역 `window.GAIA` (config, cards, enemies, engine, sfx, ui). fetch 안 씀.
- `js/engine.js`는 DOM을 모름. 상태 `S`, 이벤트 큐 `S.events` → `ui.js`가 `playEvents()`로 SFX/파티클/의성어 연출.
- UI: vh 기준 크기, 필드 영역 약 3.3~4.2:1, 손패 그리드. 효과: `burst`, `comic`, `flash`, `fieldShake`, `flyCard`. 카드 DOM에 `data-uid`.
- SFX: `js/sfx.js` WebAudio 합성음 + 얼굴 때리는 mp3. 음소거 버튼(localStorage `gaia_mute`).
- 개발 패널(⚙): 전투 선택, 도파민/조임력/윤활도 조작, 손패에 카드 추가. URL `?enc=e1..e6`.
- 단일 HTML 빌드: `cd gaia-detective && python3 tools/build_single.py <출력경로>` → 이미지/mp3를 base64로 인라인(`GAIA_IMG`, `GAIA_SND`).
- 시뮬레이션: `node tests/sim.js 300` (무작위 플레이). 최근: 일반전 ~100% 승, 보스 ~80%, 절정 보스전당 ~1회.
- 로컬 확인: 저장소 루트에서 `python3 -m http.server 8765`, Playwright(Python, Chromium)로 스크린샷. 적이 둥실거려 클릭 시 `click(force=True)` 필요.
- Git 주의: Stop hook이 "unpushed commits"를 오탐하면 `git fetch` 후 tracking ref(update-ref)를 맞추고 `git ls-remote`로 실제 푸시 확인.
