# GAIA CITY — 로지의 뒷골목 수사 (벨트스크롤 MVP)

> **독립 실험 브랜치:** `gaia-detective-brawler`  
> **원본:** `gaia-detective-assets` 브랜치의 `gaia-detective` 카드게임  
> **실행:** `index.html` (HTML5 Canvas, 모바일 가로 우선)

## 세계관과 범위

- 기존 경찰 카드게임과 **같은 로지·가이아 시티·뒷골목 출발**. 원본 카드게임의 진행도와 세이브는 건드리지 않는다.
- 건물 내부를 탐험할 때 단면형 벨트스크롤 전투로 들어가는 형태를 검증하는 **1구역 전투 MVP**다. 장래의 도시 맵 연결·다른 건물은 아직 구현하지 않았다.
- 카드/마법은 드롭하지 않고 **경찰서에서 G로 해금해 장착한 뒤 쿨타임마다 사용**한다. 원본 카드 데이터 중 `C15`, `C24`, `C25` 세 장을 실시간 스킬로 재해석했다. 나머지 카드와 카드 일러스트는 아직 이식하지 않았다.

## 현재 구현한 것

| 시스템 | 내용 |
|---|---|

| 스타일 | GAIA CITY 스타일 핑크/살구/라벤더 벽·바닥 타일 아틀라스, 하트 패들·하네스 마네킹 등의 장식. |
| 캐릭터 | 원본 `hero_shy.png`, `enemy_barbari.png`, `enemy_bouncer.png`, `enemy_mohawk.png`를 각각 **한 장**씩 사용. 방향 전환은 좌우 반전. |
| 전투 | 골든퀘스트의 근접 공격 원리(전방 투영·측면 허용 폭·애니메이션 45% 지점 판정), 경직·밀려남·짧은 무적·피격 깜빡임. 적 기력은 가이아 세계관의 **정력**으로 해석. |
| 공격 연출 | 상단·하단 준비/타격 4프레임을 개별 투명 PNG로 표시. 원본의 빨간 공 4개는 알파 채널의 분리된 객체만 찾아 코드로 투명 처리. 캐릭터 그림 자체는 재생성하지 않음. |
| AI | 적 접근·공격 예고·근접 타격·피격·탈진 후 체포, 보상 G·콤보. 같은 적 그림에 색상 필터 변형. |

| 맵 파괴 | 타격·탈진·충돌 위치 주변의 타일을 조각 단위로 지우는 Canvas 오프스크린 합성. 아래쪽 배경이 점차 드러남. 이동 판정은 유지. |
| 비공개 배경 | 상단 `배경 선택`으로 **기기 로컬 이미지**를 선택하고 `일러스트 ON/OFF`로 표시 제어. 업로드/저장/공개 GitHub 포함 없음. 선택 이미지의 눈 부위에는 런타임 가리개 적용(제공된 1536×1097 자료 기준). |
| 조작 | 키보드 `WASD/방향키`, `J` 주먹, `K` 킥, `L` 카드 / 모바일 왼쪽 조이스틱, 오른쪽 3버튼. |

## 원본 자산 및 코드 참조

- 원본 게임: `gaia-detective/data/enemies.js`, `data/cards.js`, `data/map.js`에서 캐릭터/카드 ID와 뒷골목 출발 설정을 확인.
- 인물 자산: `assets/gaia-detective/game`의 `hero_shy`, `enemy_barbari`, `enemy_bouncer`, `enemy_mohawk` 동일 Git blob을 별도 게임 경로에도 참조.
- 소품: `assets/props/squat-fx/paddle-heart.webp`.
- 생성 타일 아틀라스: `assets/gaia_tiles.webp` (원본 고해상도 PNG는 제작 산출물로 별도 보관).
- `rozie_attack_prep.png` / `rozie_attack_hit.png`: 사용자 제공 원본의 보존용 복사본. 실제 MVP는 공을 제거한 `rozie_upper_prep.png`, `rozie_upper_hit.png`, `rozie_lower_prep.png`, `rozie_lower_hit.png`를 사용한다. `rozie_attack_*_clean.png`는 공을 제거한 전체 원본 시트.
- 골든퀘스트 참조: `Alix1211/ARPG` `src/town/town.js`의 무기 타격 범위/타이밍, `src/town/field_dungeon.js`의 경직·넉백, `src/town/dungeon.js`의 방 배치/통로 생성 개념. 원본 엔진을 통째로 붙인 것이 아니라 Canvas 벨트스크롤에 맞게 **새로 구현**함.

## 알려진 제한

1. 이 빌드는 **뒷골목 전투 실험**이다. 카드게임의 전체 시나리오·건물 11개·필드 지도와 아직 연결하지 않았다.
2. 기존 타격 효과음 파일 대신 임시 합성음을 쓴다. 향후 실제 원본 효과음 자산을 찾아 교체.
3. 캐릭터의 추가 피격 프레임/걷기 시트는 사용하지 않았다. 적의 색 변형은 현재 이미지 전체 색상 회전 방식으로 임시 적용.
4. 자동 맵은 연결된 횡스크롤 공간의 길이·타일 조합·소품 위치를 변화시킨다. ARPG의 2차원 미로 및 랜덤 던전 전체 기능과 동일하다고 주장하지 않는다.
5. 공격 그림의 불필요한 붉은 공은 원본 캐릭터 픽셀을 수정하지 않고 코드로 투명 처리했다. 다만 구분 프레임은 준비/타격 2단계뿐이며 추가 동작은 아직 없다.
6. 개인용 일러스트는 공개 저장소에 싣지 않는다. 파일을 기기에서 직접 고르는 동작이 필요하며, 앱을 새로 열면 다시 선택한다.

## 검수 포인트

- 출동 → 1~4구역 전투 → 체포·골드 획득 → 완료 → 다른 배치로 재출동.
- 경찰서 매점에서 카드 해금·장착 후 전투 중 사용했을 때 쿨타임이 정상 작동하는지 확인.
- 피격 시 체력 감소와 0.72초 무적 시간, 적의 타격 예고 느낌 확인.
- 태블릿 크롬 가로 전체 화면에서 화면 비율, 좌측 조이스틱, 오른쪽 버튼 터치 확인.
- 원본 JPG를 로컬에서 선택 → 눈가리개 적용 → 타일이 지워질 때 아래에 그림이 드러나는지 확인. OFF시 기본 그라데이션 표시.

메인 브랜치·기존 카드게임 폴더는 수정하지 않는다.
